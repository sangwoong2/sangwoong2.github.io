## this

`this` 는 함수 안에서 쓸 수 있는 값이고, 함수가 **호출될 때** 정해진다. 같은 함수라도 호출하는 방식에 따라 `this` 가 달라진다.

---

## this 가 정해지는 규칙

| 호출 방식 | 모양 | `this` |
| --- | --- | --- |
| 메서드 호출 | `객체.함수()` | 점 앞의 객체 |
| 함수 호출 | `함수()` | `undefined` |
| 생성자 호출 | `new 함수()` | 새로 만들어진 객체 |
| 지정 호출 | `함수.call(값)`, `함수.bind(값)()` | 지정한 값 |

화살표 함수는 이 규칙을 따르지 않는다. 뒤의 "화살표 함수의 this"에서 다룬다.

### 메서드 호출

점 바로 앞의 객체가 `this` 다.

```javascript
const user = {
    name: '홍길동',
    show() {
        return this.name;
    },
};

console.log(user.show());   // '홍길동'
```

같은 함수를 다른 객체에 붙여 호출하면 그 객체가 `this` 다.

```javascript
const other = { name: '김철수', show: user.show };

console.log(other.show());  // '김철수'
```

### 함수 호출

객체 없이 호출하면 `this` 는 `undefined` 다. 메서드를 변수에 담아 호출하는 경우가 여기에 해당한다. 함수만 꺼내면 객체와의 연결은 따라오지 않는다.

```javascript
const show = user.show;

show();     // TypeError: Cannot read properties of undefined (reading 'name')
```

### 지정 호출

`call` 과 `apply` 는 `this` 를 지정해서 바로 호출한다. `bind` 는 `this` 가 고정된 새 함수를 돌려준다.

```javascript
const show = user.show.bind(user);

console.log(show());                            // '홍길동'
console.log(user.show.call({ name: '임시' }));  // '임시'
```

## 화살표 함수의 this

화살표 함수는 자기 `this` 가 없다. 화살표 함수 안의 `this` 는 그 함수가 **정의된 곳**의 `this` 다. 호출 방식에 따라 바뀌지 않는다.

### 호출 방식

어떻게 호출해도 같다. 변수에 담아 호출해도 유지된다.

```javascript
class Page {
    name = '화면';
    show = () => this.name;
}

const page = new Page();
const show = page.show;

console.log(show());    // '화면'
```

### bind

`bind` 로도 바꿀 수 없다.

```javascript
const show = page.show.bind({ name: '다른 객체' });

console.log(show());    // '화면'
```

### 객체 리터럴

객체 리터럴의 `{ }` 는 `this` 를 만들지 않는다. 객체의 속성에 넣은 화살표 함수의 `this` 는 그 객체가 아니라 객체를 만든 곳의 `this` 다.

```javascript
const user = {
    name: '홍길동',
    show: () => this,
};

console.log(user.show());   // undefined  (user 가 아니다)
```

## 클래스에서의 this

### 메서드를 넘길 때

메서드를 다른 곳에 넘기면 함수만 넘어간다. 받은 쪽이 객체 없이 호출하므로 `this` 가 `undefined` 다.

```javascript
class Page {
    name = '화면';

    show() {
        return this.name;
    }
}

const page = new Page();
const callback = page.show;     // 이벤트에 넘긴 것과 같은 상황

callback();     // TypeError: Cannot read properties of undefined (reading 'name')
```

### 필드에 담은 화살표 함수

필드는 객체가 만들어질 때 실행되므로, 그때의 `this` 는 만들어지는 객체다. 화살표 함수는 그 `this` 를 그대로 쓴다. 넘겨도 `this` 가 유지된다.

```javascript
class Page {
    name = '화면';
    show = () => this.name;
}

const callback = new Page().show;

console.log(callback());    // '화면'
```

### 객체로 묶은 함수

필드에 객체를 넣고 그 안에 함수를 둘 때, 화살표 함수면 `this` 가 화면 객체다.

```javascript
class Page {
    name = '화면';

    handle = {
        onClick: () => this.name,
    };
}

console.log(new Page().handle.onClick());   // '화면'
```

메서드 축약으로 쓰면 점 앞의 객체인 `handle` 이 `this` 가 된다.

```javascript
class Page {
    name = '화면';

    handle = {
        onClick() {
            return this.name;
        },
    };
}

console.log(new Page().handle.onClick());   // undefined  (handle 에는 name 이 없다)
```

### 콜백 안의 this

메서드 안에서 넘기는 콜백이 일반 함수면 그 함수의 `this` 는 `undefined` 다. 화살표 함수면 메서드의 `this` 를 그대로 쓴다.

```javascript
class Page {
    rate = 2;
    rows = [1, 2];

    calc() {
        return this.rows.map((n) => n * this.rate);
    }
}

console.log(new Page().calc());     // [2, 4]
```

## bind

`함수.bind(값)` 은 `this` 가 그 값으로 고정된 새 함수를 돌려준다. 원래 함수는 바뀌지 않는다.

### 새 함수

호출할 때마다 새 함수가 만들어진다. 같은 인자로 두 번 호출한 결과도 서로 다른 함수다.

```javascript
const f = function () {};

console.log(f.bind(null) === f.bind(null));     // false
```

### 다시 bind

한 번 고정된 `this` 는 다시 `bind` 해도 바뀌지 않는다.

```javascript
const f = function () {
    return this.n;
};
const g = f.bind({ n: 1 }).bind({ n: 2 });

console.log(g());   // 1
```

### 생성자에서 bind

메서드를 `this` 가 고정된 함수로 바꿔 필드에 넣는 방식이다. 필드에 화살표 함수를 담는 것과 결과가 같다.

```javascript
class Page {
    constructor() {
        this.name = '화면';
        this.show = this.show.bind(this);
    }

    show() {
        return this.name;
    }
}

const callback = new Page().show;

console.log(callback());    // '화면'
```

## 메서드, 필드 화살표 함수 비교

| | 메서드 `show() { }` | 필드 `show = () => { }` |
| --- | --- | --- |
| 저장되는 곳 | 클래스에 하나 | 객체마다 하나 |
| `this` | 호출할 때 정해진다 | 그 객체로 고정된다 |
| 다른 곳에 넘겼을 때 | `this` 가 `undefined` | `this` 가 유지된다 |

```javascript
class Page {
    method() {}
    field = () => {};
}

const a = new Page();
const b = new Page();

console.log(a.method === b.method);     // true
console.log(a.field === b.field);       // false
```

---

## 정리

- `this`: 함수가 호출될 때 정해지는 값.
- 메서드 호출 `객체.함수()`: 점 앞의 객체가 `this` 다.
- 함수 호출 `함수()`: `this` 는 `undefined` 다. 메서드를 변수에 담거나 넘겨서 호출하면 이렇게 된다.
- 화살표 함수: 자기 `this` 가 없고, 정의된 곳의 `this` 를 쓴다. `bind` 로도 바뀌지 않는다.
- 클래스의 필드에 담은 화살표 함수: `this` 가 그 객체로 고정된다.
- `bind`: `this` 가 고정된 새 함수를 돌려준다.
