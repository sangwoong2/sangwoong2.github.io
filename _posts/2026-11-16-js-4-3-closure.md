## 클로저

클로저는 함수가 자신이 정의된 스코프의 변수를 계속 쓸 수 있는 것이다. 그렇게 바깥 변수를 쓰는 함수 자체를 클로저라고 부르기도 한다.

### 바깥 함수가 끝난 뒤

바깥 함수의 실행이 끝나도, 안쪽 함수가 쓰는 변수는 사라지지 않는다.

```javascript
const makeCounter = () => {
    let count = 0;

    return () => {
        count += 1;
        return count;
    };
};

const counter = makeCounter();  // makeCounter 는 여기서 끝났다

console.log(counter());     // 1
console.log(counter());     // 2
console.log(counter());     // 3
```

### 호출마다 새 변수

바깥 함수를 호출할 때마다 스코프가 새로 만들어진다. 각 호출에서 만들어진 함수는 서로 다른 변수를 쓴다.

```javascript
const a = makeCounter();
const b = makeCounter();

console.log(a());   // 1
console.log(a());   // 2
console.log(b());   // 1
```

### 붙잡는 대상

값이 아니라 변수다. 함수가 만들어진 뒤에 변수의 값이 바뀌면, 함수는 바뀐 값을 본다.

```javascript
let step = '1';
const show = () => step;

step = '2';

console.log(show());    // '2'
```

### 같은 스코프의 함수들

같은 스코프에서 만들어진 함수들은 같은 변수를 함께 쓴다.

```javascript
const make = () => {
    let total = 0;

    return {
        add: (n) => { total += n; },
        get: () => total,
    };
};

const acc = make();
acc.add(5);
acc.add(3);

console.log(acc.get());     // 8
```

## 클로저의 쓰임

### 값 숨기기

바깥에서 변수에 직접 접근할 수 없다. 돌려준 함수를 통해서만 읽고 쓸 수 있다.

```javascript
console.log(acc.get());     // 8
console.log(acc.total);     // undefined
```

### 값 기억하기

호출이 끝나도 변수가 남아 있으므로, 이전 호출의 결과를 다음 호출에서 쓸 수 있다.

```javascript
const makeCache = (load) => {
    const cache = {};

    return (key) => {
        if (!(key in cache)) {
            cache[key] = load(key);     // 처음 한 번만 실행된다
        }
        return cache[key];
    };
};
```

### 인자 미리 넣기

함수를 돌려주는 함수로, 일부 인자가 정해진 함수를 만든다.

```javascript
const multiply = (a) => (b) => a * b;
const double = multiply(2);

console.log(double(5));     // 10
```

이벤트에 인자가 정해진 함수를 넘길 때도 같은 원리다. 화살표 함수가 바깥의 `step` 을 붙잡고 있다.

```javascript
const handlers = ['1', '2'].map((step) => () => onClickStep(step));
```

## 반복문의 클로저

`var` 로 선언한 반복 변수는 하나뿐이라 모든 함수가 같은 변수를 본다. `let` 은 반복마다 새 변수가 만들어진다.

```javascript
const a = [];
for (var i = 0; i < 3; i++) {
    a.push(() => i);
}
console.log(a.map((f) => f()));     // [3, 3, 3]

const b = [];
for (let j = 0; j < 3; j++) {
    b.push(() => j);
}
console.log(b.map((f) => f()));     // [0, 1, 2]
```

## 옛 값

함수가 붙잡은 변수가 더 이상 최신 값을 가리키지 않게 되는 경우다.

### 복사해 둔 값

값을 다른 변수에 복사해 두고 그 변수를 붙잡으면, 원래 변수가 바뀌어도 복사해 둔 값을 본다.

```javascript
let qty = 1;
const saved = qty;
const show = () => saved;

qty = 2;

console.log(show());    // 1
```

### 교체된 객체

객체의 내용을 바꾸면 함수도 바뀐 내용을 본다. 변수에 새 객체를 넣어 교체하면, 예전 객체를 붙잡은 함수는 예전 내용을 본다.

```javascript
const state = { qty: 1 };
const show = () => state.qty;

state.qty = 2;

console.log(show());    // 2
```

```javascript
let state = { qty: 1 };
const old = state;
const show = () => old.qty;

state = { qty: 2 };     // 새 객체로 교체

console.log(show());    // 1
```

## 정리

- 클로저: 함수가 자신이 정의된 스코프의 변수를 계속 쓸 수 있는 것.
- 바깥 함수가 끝나도 안쪽 함수가 쓰는 변수는 남는다. 바깥 함수를 호출할 때마다 변수가 새로 만들어진다.
- 붙잡는 대상은 값이 아니라 변수다. 변수가 바뀌면 바뀐 값을 본다.
- 쓰임: 값 숨기기, 값 기억하기, 인자 미리 넣기.
- 옛 값: 복사해 둔 값이나 교체되기 전의 객체를 붙잡으면 최신 값을 보지 못한다.
