## 문자열

문자열은 글자를 순서대로 나열한 값이다. 기본형이다.

### 변경 불가

만들어진 문자열의 내용은 바꿀 수 없다. 문자열 메서드는 원본을 바꾸지 않고 새 문자열을 돌려준다. 돌려준 값을 받지 않으면 아무 일도 일어나지 않는다.

```javascript
const s = ' abc ';
s.trim();

console.log(s);             // ' abc '
console.log(s.trim());      // 'abc'
```

### 템플릿 문자열

백틱(`` ` ``)으로 감싼 문자열이다. `${ }` 안에 적은 식의 결과가 문자열로 변환되어 그 자리에 들어간다.

```javascript
const count = 3;

console.log(`${count}건 조회되었습니다.`);  // '3건 조회되었습니다.'
```

## 문자열 메서드

모두 원본을 바꾸지 않는다.

| 메서드 | 하는 일 | 돌려주는 값 |
| --- | --- | --- |
| `indexOf(찾을 것)` | 처음 나오는 위치를 찾는다 | 위치. 없으면 `-1` |
| `includes(찾을 것)` | 들어 있는지 확인한다 | 불리언 |
| `startsWith`, `endsWith` | 그것으로 시작하는지, 끝나는지 확인한다 | 불리언 |
| `substring(시작, 끝)` | 시작부터 끝 앞까지 자른다 | 문자열 |
| `slice(시작, 끝)` | 시작부터 끝 앞까지 자른다 | 문자열 |
| `substr(시작, 길이)` | 시작부터 길이만큼 자른다 | 문자열 |
| `replace(찾을 것, 바꿀 것)` | 처음 하나를 바꾼다 | 문자열 |
| `replaceAll(찾을 것, 바꿀 것)` | 전부 바꾼다 | 문자열 |
| `trim()` | 앞뒤 공백을 없앤다 | 문자열 |
| `toUpperCase()`, `toLowerCase()` | 대문자, 소문자로 바꾼다 | 문자열 |
| `padStart(길이, 글자)`, `padEnd` | 길이가 될 때까지 앞, 뒤를 채운다 | 문자열 |
| `split(구분자)` | 구분자로 나눈다 | 배열 |
| `match(정규식)` | 패턴에 맞는 부분을 찾는다 | 배열. 없으면 `null` |

찾기 메서드는 모두 대소문자를 구분한다.

---

## 자르기 메서드의 차이

`substring`, `slice`, `substr` 은 하는 일이 비슷하지만 인자의 뜻이 다르다.

| | `substring` | `slice` | `substr` |
| --- | --- | --- | --- |
| 두 번째 인자 | 끝 위치 | 끝 위치 | 길이 |
| 음수 | 0 으로 취급 | 뒤에서부터 센다 | 뒤에서부터 센다 |
| 시작이 끝보다 클 때 | 둘을 바꿔서 자른다 | 빈 문자열 | 해당 없음 |

### 두 번째 인자

`substring` 과 `slice` 는 끝 위치, `substr` 은 길이다.

```javascript
console.log('20261116'.substring(4, 6));    // '11'
console.log('20261116'.slice(4, 6));        // '11'
console.log('20261116'.substr(4, 2));       // '11'
console.log('20261116'.substr(4, 6));       // '1116'
```

### 음수

```javascript
console.log('20261116'.slice(-2));          // '16'
console.log('20261116'.substr(-2));         // '16'
console.log('20261116'.substring(-2));      // '20261116'
```

## replace

### 바뀌는 개수

찾을 것을 문자열로 주면 처음 나오는 하나만 바뀐다.

```javascript
console.log('a-b-c'.replace('-', ''));      // 'ab-c'
```

전부 바꾸려면 `g` 플래그가 붙은 정규식을 주거나 `replaceAll` 을 쓴다.

```javascript
console.log('a-b-c'.replace(/-/g, ''));     // 'abc'
console.log('a-b-c'.replaceAll('-', ''));   // 'abc'
```

## split

### 구분자가 없을 때

원래 문자열 하나가 든 배열이 나온다. 빈 문자열을 나눠도 빈 배열이 아니다.

```javascript
console.log('abc'.split(','));      // ['abc']
console.log(''.split(','));         // ['']
console.log(''.split(',').length);  // 1
```

### 연속된 구분자

사이에 빈 문자열이 들어간다.

```javascript
console.log('a,,c'.split(','));     // ['a', '', 'c']
```

## 대소 비교

`<`, `>` 로 문자열을 비교하면 앞 글자부터 차례로 글자의 코드 값을 비교한다.

### 숫자 문자열

숫자의 크기가 아니라 글자 순서로 비교된다.

```javascript
console.log('10' < '9');    // true  ('1' 이 '9' 보다 작다)
console.log(10 < 9);        // false
```

자릿수가 같으면 숫자의 크기 순서와 결과가 같다.

```javascript
console.log('20261116' < '20261201');   // true
```

### 대문자와 소문자

대문자가 소문자보다 코드 값이 작다.

```javascript
console.log('B' < 'a');     // true
```

## 정규식

정규식은 문자열의 패턴을 나타내는 객체다. `/패턴/플래그` 로 적는다.

### 패턴 기호

| 기호 | 뜻 |
| --- | --- |
| `^`, `$` | 문자열의 시작, 끝 |
| `.` | 아무 글자 하나 |
| `\d`, `\s` | 숫자 하나, 공백 하나 |
| `[abc]`, `[^abc]` | a, b, c 중 하나, 그 외의 글자 하나 |
| `+`, `*`, `{8}` | 앞의 것이 1번 이상, 0번 이상, 8번 |
| `( )` | 묶음. 찾은 내용을 `$1`, `$2` 로 꺼내 쓴다 |
| `\.` | 점 글자 자체. 기호를 글자로 쓰려면 앞에 `\` 를 붙인다 |

### 플래그

`g` 는 처음 하나가 아니라 전부를 대상으로 하고, `i` 는 대소문자를 구분하지 않는다.

### 쓰는 곳

`test` 는 패턴에 맞는지를 불리언으로 돌려준다. `replace` 는 패턴에 맞는 부분을 바꾼다.

```javascript
console.log(/^\d{8}$/.test('20261116'));    // true
console.log(/^\d{8}$/.test('2026-11-16'));  // false

console.log('010-1234-5678'.replace(/[^0-9]/g, ''));                    // '01012345678'
console.log('20261116'.replace(/(\d{4})(\d{2})(\d{2})/, '$1-$2-$3'));   // '2026-11-16'
```

### 점

`.` 은 아무 글자를 뜻한다. 점 글자를 찾으려면 `\.` 로 적는다.

```javascript
console.log('a.b'.replace(/./g, 'x'));      // 'xxx'
console.log('a.b'.replace(/\./g, 'x'));     // 'axb'
```

### match 의 결과

맞는 부분이 없으면 빈 배열이 아니라 `null` 이다.

```javascript
console.log('a1b22c'.match(/\d+/g));    // ['1', '22']
console.log('abc'.match(/\d+/g));       // null
```

## 정리

- 문자열: 내용을 바꿀 수 없다. 메서드는 새 문자열을 돌려준다.
- 자르기: `substring` 과 `slice` 의 두 번째 인자는 끝 위치, `substr` 은 길이다.
- `replace`: 문자열로 찾으면 처음 하나만 바꾼다.
- `split`: 빈 문자열을 나누면 `['']` 이다.
- 대소 비교: 글자 순서로 비교한다. `'10' < '9'` 는 `true` 다.
- 정규식: 문자열의 패턴. `.` 은 아무 글자이고, `match` 는 못 찾으면 `null` 이다.
