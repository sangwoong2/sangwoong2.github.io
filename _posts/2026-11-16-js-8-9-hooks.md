## 함수형 컴포넌트

함수형 컴포넌트는 props 를 받아 화면을 돌려주는 함수다. 클래스가 없으므로 인스턴스도 `this` 도 없다.

```jsx
function Counter(props) {
    return <div>{props.title}</div>;
}
```

### 다시 그리기

다시 그릴 때마다 함수 전체가 처음부터 다시 실행된다. 함수 안의 지역 변수와 함수는 매번 새로 만들어진다.

---

## Hook

Hook 은 함수형 컴포넌트에서 state 와 생명주기 같은 기능을 쓰게 해 주는 함수다. 이름이 `use` 로 시작한다.

### 클래스형과의 대응

| 클래스형 | 함수형 |
| --- | --- |
| `state = { count: 0 }` | `const [count, setCount] = useState(0)` |
| `this.setState({ count: 1 })` | `setCount(1)` |
| `this.props.title` | `props.title` |
| `componentDidMount`, `componentDidUpdate`, `componentWillUnmount` | `useEffect` |
| `React.createRef()` | `useRef()` |
| `static contextType`, `this.context` | `useContext(Context)` |
| 메서드, 필드에 담은 함수 | 함수 안의 지역 함수 |

---

## useState

`useState(초기값)` 은 `[현재 값, 값을 바꾸는 함수]` 를 돌려준다. 값을 바꾸는 함수를 호출하면 컴포넌트가 다시 그려진다.

```jsx
function Counter() {
    const [count, setCount] = useState(0);

    return <button onClick={() => setCount(count + 1)}>{count}</button>;
}
```

함수가 다시 실행되어도 값이 초기값으로 돌아가지 않는다. React 가 값을 기억해 두었다가 `useState` 가 그 값을 돌려준다. 초기값은 처음 한 번만 쓰인다.

### 병합

하지 않는다. 넘긴 값으로 통째로 바뀐다. 클래스형의 `setState` 와 다르다.

```javascript
const [cond, setCond] = useState({ a: 1, b: 2 });

setCond({ a: 9 });              // cond 는 { a: 9 }  (b 가 사라진다)
setCond({ ...cond, a: 9 });     // cond 는 { a: 9, b: 2 }
```

### 같은 참조

같은 참조를 넘기면 다시 그려지지 않는다. 배열을 직접 수정하고 같은 배열을 넘기면 화면이 바뀌지 않는다.

```javascript
rows.push(row);
setRows(rows);              // 다시 그려지지 않는다
setRows([...rows, row]);    // 다시 그려진다
```

### 한 번의 실행 안에서의 값

`count` 는 그 실행에서 만들어진 지역 변수다. 값을 바꾸는 함수를 호출해도 그 변수는 바뀌지 않는다. 다음 실행에서 새 값이 들어온다.

```javascript
const onClick = () => {
    // count 는 0
    setCount(count + 1);    // setCount(1)
    setCount(count + 1);    // setCount(1)
    setCount(count + 1);    // setCount(1)
};
// 결과: 1
```

이전 값으로 계산하려면 함수를 넘긴다.

```javascript
setCount((prev) => prev + 1);
setCount((prev) => prev + 1);
// 결과: 2 증가
```

## useEffect

`useEffect(함수, 의존 배열)` 은 화면이 그려진 뒤에 실행할 함수를 등록한다. 의존 배열이 언제 다시 실행할지를 정한다.

### 의존 배열

| 의존 배열 | 함수가 실행되는 때 |
| --- | --- |
| `[]` | 처음 그려진 뒤 한 번 |
| `[a, b]` | 처음 그려진 뒤, 그리고 `a` 나 `b` 가 바뀌어 다시 그려진 뒤 |
| 생략 | 그려질 때마다 |

```jsx
useEffect(() => {
    load(itemCd);
}, [itemCd]);
```

### 정리 함수

등록한 함수가 함수를 돌려주면, 그 함수는 다음 실행 직전과 컴포넌트가 사라질 때 호출된다. 타이머와 구독을 해제하는 자리다.

```jsx
useEffect(() => {
    const timer = setInterval(refresh, 60000);

    return () => clearInterval(timer);
}, []);
```

값 `n` 이 0 에서 1 로 바뀔 때의 순서다.

```
함수 본문 실행 (n=1) → 이전 정리 함수 (n=0) → 새 함수 (n=1)
```

## 옛 값

함수형 컴포넌트의 함수들은 그 실행에서 만들어진 변수를 붙잡는다. 나중에 호출되는 함수는 만들어졌을 때의 값을 본다. 4-3 "클로저"의 옛 값이다.

```jsx
function Counter() {
    const [count, setCount] = useState(0);

    useEffect(() => {
        const timer = setInterval(() => {
            console.log(count);     // 항상 0
        }, 1000);

        return () => clearInterval(timer);
    }, []);     // 처음 한 번만 실행된다

    return <button onClick={() => setCount(count + 1)}>{count}</button>;
}
```

의존 배열이 `[]` 라서 `useEffect` 의 함수는 처음 실행에서 한 번만 만들어진다. 그 안의 타이머 콜백은 처음 실행의 `count` 인 0 을 계속 본다. 화면의 숫자가 올라가도 콜백이 출력하는 값은 0 이다.

클래스형에서는 `this.state.count` 로 읽기 때문에 이 문제가 없다. `this` 는 같은 인스턴스를 가리키고, 읽는 시점의 값이 나온다.

## useRef

`useRef(초기값)` 은 `{ current: 초기값 }` 객체를 돌려준다. 다시 그려져도 같은 객체가 유지되고, `current` 를 바꿔도 다시 그려지지 않는다.

```jsx
const inputRef = useRef(null);

return <input ref={inputRef} />;
```

## Hook 의 규칙

Hook 은 컴포넌트 함수의 맨 바깥에서만 호출한다. 조건문, 반복문, 중첩된 함수 안에서 호출하지 않는다. React 는 Hook 을 호출된 순서로 구분하기 때문에, 실행할 때마다 같은 순서로 같은 개수가 호출되어야 한다.

```jsx
function Page({ visible }) {
    if (visible) {
        const [count, setCount] = useState(0);  // 조건문 안에서 호출했다
    }
}
// Error: Rendered more hooks than during the previous render.
```

컴포넌트 밖에서 호출해도 에러가 난다.

```
Error: Invalid hook call. Hooks can only be called inside of the body of a function component.
```

---

## 정리

- 함수형 컴포넌트: props 를 받아 화면을 돌려주는 함수. 다시 그릴 때마다 함수 전체가 다시 실행된다.
- `useState`: `[값, 바꾸는 함수]` 를 돌려준다. 병합하지 않고 통째로 바꾼다.
- 값은 그 실행의 지역 변수다. 바꾸는 함수를 호출해도 그 실행 안에서는 바뀌지 않는다.
- `useEffect`: 그려진 뒤에 실행할 함수를 등록한다. 의존 배열로 실행 시점을 정한다.
- 나중에 호출되는 함수는 만들어졌을 때의 값을 본다.
- Hook 은 컴포넌트 함수의 맨 바깥에서만 호출한다.
