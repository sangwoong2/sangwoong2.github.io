## getter

getter 는 속성을 읽을 때 실행되는 메서드다. `get 이름() { }` 으로 만들고, 호출할 때 `( )` 를 붙이지 않는다.

```javascript
class Page {
    props = { util: '공통 유틸' };

    get util() {
        return this.props.util;
    }
}

const page = new Page();

console.log(page.util);     // '공통 유틸'
```

### 읽는 방법

속성처럼 읽는다. `( )` 를 붙이면 getter 가 돌려준 값을 함수로 호출하게 된다.

```javascript
console.log(page.util);     // '공통 유틸'
console.log(page.util());   // TypeError: page.util is not a function
```

### 실행 시점

읽을 때마다 실행된다. 값을 저장해 두지 않는다.

```javascript
let count = 0;

class Counter {
    get value() {
        count += 1;
        return count;
    }
}

const c = new Counter();
c.value;
c.value;

console.log(c.value);   // 3
```

### 할당

setter 가 없으면 값을 넣을 수 없다.

```javascript
page.util = '다른 값';      // TypeError: Cannot set property util of #<Page> which has only a getter
```

## getter, 필드의 차이

getter 는 읽는 시점에 계산하고, 필드는 인스턴스를 만들 때 한 번 계산해서 저장한다.

### 원래 값이 바뀐 뒤

getter 는 바뀐 값을 돌려주고, 필드는 처음 저장한 값을 그대로 갖고 있다.

```javascript
class A {
    props = { util: 'u1' };
    get util() { return this.props.util; }
}

class B {
    props = { util: 'u1' };
    util = this.props.util;
}

const a = new A();
const b = new B();
a.props = { util: 'u2' };
b.props = { util: 'u2' };

console.log(a.util);    // 'u2'
console.log(b.util);    // 'u1'
```

### 저장되는 곳

getter 는 클래스에 저장된다. 인스턴스의 속성 목록에 나오지 않는다.

```javascript
class Page {
    name = '화면';
    get title() { return this.name + ' 제목'; }
}

const page = new Page();

console.log(page.title);            // '화면 제목'
console.log(Object.keys(page));     // ['name']
console.log(JSON.stringify(page));  // '{"name":"화면"}'
console.log({ ...page });           // { name: '화면' }
```

### 구조분해

꺼낸 시점의 값이 변수에 담긴다. 그 뒤에 값이 바뀌어도 변수는 바뀌지 않는다.

```javascript
class Page {
    n = 1;
    get value() { return this.n; }
}

const page = new Page();
const { value } = page;

page.n = 9;

console.log(value);         // 1
console.log(page.value);    // 9
```

## getter, 필드, 메서드 비교

| | getter | 필드 | 메서드 |
| --- | --- | --- | --- |
| 모양 | `get util() { }` | `util = 값;` | `util() { }` |
| 읽기 | `this.util` | `this.util` | `this.util()` |
| 계산하는 때 | 읽을 때마다 | 인스턴스를 만들 때 한 번 | 호출할 때마다 |
| 저장되는 곳 | 클래스 | 인스턴스 | 클래스 |
| 값 넣기 | setter 가 없으면 불가 | 가능 | 가능 |

## setter

setter 는 속성에 값을 넣을 때 실행되는 메서드다. `set 이름(값) { }` 으로 만든다.

```javascript
class Page {
    _qty = 0;

    get qty() {
        return this._qty;
    }

    set qty(value) {
        this._qty = value * 2;
    }
}

const page = new Page();
page.qty = 5;

console.log(page.qty);  // 10
```

---

## 객체의 getter

객체 리터럴에도 만들 수 있다. 객체에 직접 만든 getter 는 속성 목록에 나온다.

```javascript
const o = {
    a: 1,
    get b() { return this.a + 1; },
};

console.log(o.b);               // 2
console.log(JSON.stringify(o)); // '{"a":1,"b":2}'
```

---

## 정리

- getter: 속성을 읽을 때 실행되는 메서드. `( )` 없이 읽는다.
- 읽을 때마다 실행되므로 원래 값이 바뀌면 바뀐 값을 돌려준다. 필드는 처음 저장한 값을 갖고 있다.
- setter 가 없으면 값을 넣을 수 없다.
- 클래스의 getter 는 인스턴스의 속성 목록, JSON 변환, 스프레드에 나오지 않는다.
- setter: 속성에 값을 넣을 때 실행되는 메서드.
