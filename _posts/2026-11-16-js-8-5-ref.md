## ref

ref 는 화면에 그려진 컴포넌트의 인스턴스나 HTML 요소를 가리키는 객체다. `current` 라는 속성 하나를 갖고, 그 안에 가리키는 대상이 들어 있다.

### 만들기와 연결

`React.createRef()` 로 만들고, 태그의 `ref` 속성에 넘긴다.

```jsx
class Page extends React.Component {
    gridRef = React.createRef();

    render() {
        return <Grid ref={this.gridRef} />;
    }
}
```

### current 에 들어 있는 것

| `ref` 를 넘긴 대상 | `current` |
| --- | --- |
| 클래스 컴포넌트 | 그 컴포넌트의 인스턴스 |
| HTML 태그 | 그 HTML 요소 |

---

## current 가 채워지는 시점

만든 직후에는 `null` 이다. 화면에 그려진 뒤에 채워진다.

| 시점 | `current` |
| --- | --- |
| `constructor`, 필드 초기화 | `null` |
| 처음 `render` 가 실행되는 동안 | `null` |
| `componentDidMount` 부터 | 대상 |
| 대상이 화면에서 사라진 뒤 | `null` |

```jsx
class Page extends React.Component {
    gridRef = React.createRef();

    constructor(props) {
        super(props);
        console.log(this.gridRef.current);  // null
    }

    componentDidMount() {
        console.log(this.gridRef.current);  // Grid 인스턴스
    }

    render() {
        return <Grid ref={this.gridRef} />;
    }
}
```

---

## 컴포넌트의 메서드 호출

`current` 가 인스턴스이므로 그 컴포넌트의 메서드를 직접 호출할 수 있다. 부모가 자식에게 동작을 시킬 때 쓴다.

```jsx
onClickSearch = () => {
    this.gridRef.current.search();
};
```

### 대상이 없을 때

조건부 렌더링으로 대상이 그려지지 않았으면 `current` 가 `null` 이다. 그대로 호출하면 에러가 난다.

```javascript
this.gridRef.current.search();      // TypeError: Cannot read properties of null (reading 'search')
this.gridRef.current?.search();     // undefined  (호출하지 않는다)
```

---

## HTML 요소

`current` 가 HTML 요소이므로 요소의 속성과 메서드를 쓸 수 있다.

```jsx
inputRef = React.createRef();

onClickFocus = () => {
    this.inputRef.current.focus();
    console.log(this.inputRef.current.value);
};

render() {
    return <input ref={this.inputRef} />;
}
```

---

## 함수형 컴포넌트

함수형 컴포넌트에는 인스턴스가 없어서 `ref` 를 넘길 수 없다. 경고가 나오고 `current` 는 `null` 로 남는다.

```
Warning: Function components cannot be given refs. Attempts to access this ref will fail.
```

---

## ref, state 비교

| | ref | state |
| --- | --- | --- |
| 담는 것 | 인스턴스, HTML 요소 | 화면에 그릴 데이터 |
| 값이 바뀌면 | 다시 그려지지 않는다 | 다시 그려진다 |
| 바꾸는 방법 | React 가 `current` 를 채운다 | `setState` |

---

## props, ref 로 자식 다루기

| | props | ref |
| --- | --- | --- |
| 방식 | 값을 넘기면 자식이 그 값으로 그려진다 | 자식의 메서드를 직접 호출한다 |
| 쓰는 경우 | 자식이 보여 줄 데이터 | 조회 실행, 포커스 이동 같은 동작 |

---

## 정리

- ref: 컴포넌트 인스턴스나 HTML 요소를 가리키는 객체. `current` 에 대상이 들어 있다.
- `current` 는 `componentDidMount` 부터 채워진다. 그 전과 대상이 사라진 뒤에는 `null` 이다.
- 컴포넌트에 연결한 ref 로 그 컴포넌트의 메서드를 호출한다.
- 대상이 그려지지 않았을 수 있으면 `?.` 로 호출한다.
- 함수형 컴포넌트에는 `ref` 를 넘길 수 없다.
- ref 가 바뀌어도 다시 그려지지 않는다.
