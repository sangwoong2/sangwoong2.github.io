## 모듈

모듈은 파일 하나다. 파일마다 자기 스코프를 갖고, 내보낸(`export`) 것만 다른 파일에서 가져다(`import`) 쓸 수 있다.

```javascript
// util.js
const hidden = '내보내지 않은 변수';

export const PAGE_SIZE = 50;
```

```javascript
// main.js
import { PAGE_SIZE } from './util.js';

console.log(PAGE_SIZE);     // 50
```

---

## export

내보내는 방법은 두 가지다.

| | 이름 붙인 내보내기 | 기본 내보내기 |
| --- | --- | --- |
| 모양 | `export const a = 1;` | `export default 값;` |
| 파일당 개수 | 여러 개 | 하나 |
| 가져올 때 | `import { a } from '...'` | `import 아무이름 from '...'` |
| 가져올 때의 이름 | 내보낸 이름과 같아야 한다 | 자유롭게 정한다 |

```javascript
// util.js
export const PAGE_SIZE = 50;
export function format(n) {
    return n + '건';
}

export default class LogisUtil {}
```

---

## import

### 중괄호

이름 붙인 내보내기는 `{ }` 안에 적고, 기본 내보내기는 `{ }` 없이 적는다. 한 줄에 함께 쓸 수 있다.

```javascript
import LogisUtil, { PAGE_SIZE, format } from './util.js';
```

기본 내보내기를 `{ }` 안에 적으면 그 이름의 이름 붙인 내보내기를 찾는다. 없으면 에러가 난다.

```javascript
import { LogisUtil } from './util.js';
// SyntaxError: The requested module './util.js' does not provide an export named 'LogisUtil'
```

번들러(webpack)로 빌드하는 환경에서는 이 경우 에러 대신 경고가 나오고 값이 `undefined` 가 될 수 있다.

### 이름

이름 붙인 내보내기는 `as` 로 이름을 바꿔 가져온다. 기본 내보내기는 가져오는 쪽에서 이름을 정한다.

```javascript
import { format as fmt } from './util.js';
import Util from './util.js';       // LogisUtil 을 Util 이라는 이름으로 가져온다
```

### 전체 가져오기

`import * as 이름` 은 내보낸 것 전부를 객체 하나로 가져온다. 기본 내보내기는 `default` 라는 키에 들어 있다.

```javascript
import * as util from './util.js';

console.log(Object.keys(util));     // ['PAGE_SIZE', 'default', 'format']
console.log(util.hidden);           // undefined  (내보내지 않은 것은 없다)
```

### 경로

| 경로 | 가져오는 곳 |
| --- | --- |
| `'./util'`, `'../common/util'` | 지금 파일을 기준으로 한 다른 파일 |
| `'react'`, `'luna-orbit'` | 설치된 패키지 (`node_modules`) |

## 모듈의 동작

### 한 번만 실행

모듈의 코드는 처음 가져올 때 한 번만 실행된다. 여러 파일에서 가져와도 다시 실행되지 않고, 모두 같은 것을 함께 쓴다.

```javascript
// util.js
console.log('util 실행');
export const cache = {};
```

```javascript
// a.js 와 b.js 가 모두 util.js 를 가져와도 'util 실행' 은 한 번만 출력된다
// a.js 에서 cache 에 넣은 값을 b.js 에서 읽을 수 있다
```

### 읽기 전용

가져온 변수에는 값을 넣을 수 없다. 내보낸 쪽에서 `let` 으로 선언했어도 마찬가지다.

```javascript
import { count } from './util.js';

count = 5;      // TypeError: Assignment to constant variable.
```

### 값의 연결

가져온 변수는 내보낸 쪽 변수와 연결되어 있다. 내보낸 쪽에서 값을 바꾸면 가져온 쪽에서도 바뀐 값이 보인다.

```javascript
// util.js
export let count = 0;
export const increase = () => { count += 1; };
```

```javascript
import { count, increase } from './util.js';

console.log(count);     // 0
increase();
console.log(count);     // 1
```

### this

모듈의 맨 바깥에서 `this` 는 `undefined` 다. 모듈은 항상 엄격 모드로 실행된다.

## 동적 import

`import(경로)` 는 함수처럼 호출하는 형태다. 실행되는 시점에 모듈을 가져오고, Promise 를 돌려준다. 결과는 `import * as` 로 가져온 것과 같은 객체다.

```javascript
const module = await import('./util.js');

console.log(Object.keys(module));       // ['PAGE_SIZE', 'default', 'format']
console.log(typeof module.default);     // 'function'
```

### 화면 단위로 나누기

`import ... from` 은 파일이 처음 실행될 때 모두 가져온다. `import()` 는 그 줄이 실행될 때 가져온다. 화면을 열 때 그 화면의 코드를 가져오는 데 쓴다.

```javascript
export const BLE0030 = React.lazy(() => import('./BLE0000/BLE0030/BLE0030'));
```

## require

`import` 문법이 생기기 전에 쓰던 가져오기 방식이다. 함수 호출이라서 조건문이나 식 안에 쓸 수 있다.

```javascript
const moment = require('moment');
```

번들러 환경에서는 이미지 같은 파일을 가져오는 데도 쓴다. 이때 돌려주는 값은 그 파일의 주소다.

```javascript
const icon = require('./imgs/icon.png');
```

---

## import, 동적 import, require 비교

| | `import ... from` | `import()` | `require()` |
| --- | --- | --- | --- |
| 쓰는 자리 | 파일의 맨 바깥 | 어디든 | 어디든 |
| 가져오는 때 | 파일이 실행되기 전 | 그 줄이 실행될 때 | 그 줄이 실행될 때 |
| 돌려주는 값 | 없음 (변수가 만들어진다) | Promise | 가져온 값 |

---

## 정리

- 모듈: 파일 하나. 내보낸 것만 다른 파일에서 쓸 수 있다.
- 이름 붙인 내보내기는 `{ }` 로, 기본 내보내기는 `{ }` 없이 가져온다.
- 기본 내보내기는 가져오는 쪽에서 이름을 정한다.
- 모듈의 코드는 한 번만 실행되고, 여러 파일이 같은 것을 함께 쓴다.
- 가져온 변수에는 값을 넣을 수 없다.
- `import()`: 실행 시점에 모듈을 가져오고 Promise 를 돌려준다.
