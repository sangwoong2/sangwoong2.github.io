## 객체

객체는 속성의 묶음이다. 속성은 키(이름)와 값의 쌍이다.

```javascript
const user = { name: '홍길동', age: 30 };
```

### 속성 접근

`객체.키` 또는 `객체['키']` 로 읽고 쓴다. 없는 속성을 읽으면 에러가 아니라 `undefined` 다.

```javascript
const user = { name: '홍길동' };

console.log(user.name);     // '홍길동'
console.log(user['name']);  // '홍길동'
console.log(user.age);      // undefined
```

### 점과 대괄호의 차이

점 뒤에 적은 것은 키 이름 그대로다. 대괄호 안에 적은 것은 식이고, 그 결과가 키가 된다. 키가 변수에 들어 있으면 대괄호를 써야 한다.

```javascript
const user = { name: '홍길동' };
const key = 'name';

console.log(user.key);      // undefined  ('key' 라는 속성을 찾는다)
console.log(user[key]);     // '홍길동'   (key 에 든 'name' 속성을 찾는다)
```

식별자 규칙에 맞지 않는 키도 대괄호로만 접근할 수 있다.

```javascript
const row = { 'item-cd': 'A001' };

console.log(row['item-cd']);    // 'A001'
```

### 계산된 키

객체를 만들 때 키 자리에 `[식]` 을 적으면 식의 결과가 키가 된다.

```javascript
const id = 'divCd';
const condition = { [id]: '1000', [id + 'Nm']: '본사' };

console.log(condition);     // { divCd: '1000', divCdNm: '본사' }
```

### 단축 속성

키와 값을 담은 변수의 이름이 같으면 한 번만 적는다. `{ name }` 은 `{ name: name }` 과 같다.

```javascript
const name = '홍길동';
const age = 30;

console.log({ name, age });     // { name: '홍길동', age: 30 }
```

## 키

### 타입

키는 항상 문자열이다. 숫자로 적어도 문자열로 바뀐다.

```javascript
const o = {};
o[1] = 'a';
o['1'] = 'b';

console.log(o[1]);                  // 'b'  (같은 키다)
console.log(Object.keys(o));        // ['1']
```

### 순서

정수로 된 키가 먼저 오름차순으로 나오고, 나머지 키는 넣은 순서대로 나온다.

```javascript
const o = { b: 1, 2: 'x', a: 2, 1: 'y' };

console.log(Object.keys(o));    // ['1', '2', 'b', 'a']
```

### 같은 키

같은 키를 두 번 적으면 뒤의 값이 남는다. 에러가 나지 않는다.

```javascript
console.log({ a: 1, a: 2 });    // { a: 2 }
```

## 속성의 존재

값이 `undefined` 인 속성과 없는 속성은 읽으면 둘 다 `undefined` 지만 다른 상태다.

### 구분

`'키' in 객체` 는 속성이 있으면 `true` 다.

```javascript
const o = { a: undefined };

console.log(o.a === o.b);   // true   (둘 다 undefined)
console.log('a' in o);      // true
console.log('b' in o);      // false
```

### 삭제

`delete 객체.키` 는 속성을 없앤다. `undefined` 를 할당하는 것은 속성을 남긴 채 값만 바꾼다.

```javascript
const a = { x: 1, y: 2 };
delete a.x;
console.log(Object.keys(a));    // ['y']

const b = { x: 1, y: 2 };
b.x = undefined;
console.log(Object.keys(b));    // ['x', 'y']
```

## 객체 훑기

| 방법 | 돌려주는 값 |
| --- | --- |
| `Object.keys(객체)` | 키의 배열 |
| `Object.values(객체)` | 값의 배열 |
| `Object.entries(객체)` | `[키, 값]` 의 배열 |
| `for (const 키 in 객체)` | 반복마다 키 하나 |

```javascript
const o = { a: 1, b: 2 };

console.log(Object.keys(o));        // ['a', 'b']
console.log(Object.values(o));      // [1, 2]
console.log(Object.entries(o));     // [['a', 1], ['b', 2]]
```

### for...of

객체에는 쓸 수 없다. 배열로 바꾼 뒤에 쓴다.

```javascript
const o = { a: 1 };

for (const v of o) { }                              // TypeError: o is not iterable
for (const [key, value] of Object.entries(o)) { }   // 가능
```

### 빈 객체

빈 객체는 참 같은 값이다. 비어 있는지는 키의 개수로 확인한다.

```javascript
const o = {};

console.log(o ? '참' : '거짓');             // '참'
console.log(Object.keys(o).length === 0);   // true
```

## 정리

- 객체: 속성의 묶음. 없는 속성을 읽으면 `undefined` 다.
- 점과 대괄호: 점 뒤는 키 이름 그대로, 대괄호 안은 식이다. 키가 변수에 들어 있으면 대괄호를 쓴다.
- 계산된 키: `{ [식]: 값 }`. 식의 결과가 키가 된다.
- 단축 속성: `{ name }` 은 `{ name: name }` 이다.
- 키: 항상 문자열이다. 정수 키가 먼저 오름차순으로 나온다.
- 속성의 존재: `in` 으로 확인한다. `delete` 는 속성을 없애고, `undefined` 할당은 값만 바꾼다.
- 빈 객체: 참 같은 값이다. `Object.keys(객체).length` 로 확인한다.
