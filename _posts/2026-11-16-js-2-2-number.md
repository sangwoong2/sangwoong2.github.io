## number

숫자를 나타내는 타입이다. 정수와 실수를 구분하지 않고 모든 숫자를 64비트 부동소수점 하나의 형식으로 저장한다.

### 나눗셈

결과가 정수로 잘리지 않는다.

```javascript
console.log(7 / 2);                 // 3.5
console.log(Math.floor(7 / 2));     // 3
```

### 0 으로 나누기

에러가 나지 않는다. `Infinity` 또는 `NaN` 이 나온다.

```javascript
console.log(1 / 0);     // Infinity
console.log(0 / 0);     // NaN
```

### 안전한 정수 범위

오차 없이 표현할 수 있는 정수는 `9007199254740991`(2의 53제곱 - 1)까지다. 이 범위를 넘으면 정수 계산도 틀린다.

```javascript
console.log(Number.MAX_SAFE_INTEGER);   // 9007199254740991
console.log(9007199254740991 + 2);      // 9007199254740992
```

## 숫자 함수

| 함수 | 하는 일 | 돌려주는 값 |
| --- | --- | --- |
| `Number(값)` | 숫자로 변환한다 | 숫자. 변환할 수 없으면 `NaN` |
| `parseInt(문자열)` | 앞에서부터 읽어 정수로 변환한다 | 정수. 첫 글자부터 못 읽으면 `NaN` |
| `Number.isNaN(값)` | `NaN` 인지 확인한다 | 불리언 |
| `Math.round(숫자)` | 반올림한다 | 정수 |
| `Math.floor(숫자)` | 내림한다 | 정수 |
| `Math.ceil(숫자)` | 올림한다 | 정수 |
| `Math.abs(숫자)` | 절댓값을 구한다 | 숫자 |
| `Math.max(a, b, ...)`, `Math.min` | 가장 큰 값, 작은 값을 구한다 | 숫자 |
| `숫자.toFixed(자릿수)` | 소수 자릿수를 맞춘다 | **문자열** |
| `숫자.toLocaleString()` | 천 단위 구분 기호를 넣는다 | **문자열** |

## Number, parseInt 의 차이

`Number` 는 문자열 전체가 숫자여야 변환한다. `parseInt` 는 앞에서부터 숫자로 읽을 수 있는 데까지만 읽고 소수점 아래를 버린다.

| 값 | `Number` | `parseInt` |
| --- | --- | --- |
| `'12'` | `12` | `12` |
| `'12.9'` | `12.9` | `12` |
| `'12px'` | `NaN` | `12` |
| `'1,234'` | `NaN` | `1` |
| `''` | `0` | `NaN` |
| `null` | `0` | `NaN` |

### 쉼표가 있는 문자열

`Number` 는 `NaN`, `parseInt` 는 쉼표 앞까지만 읽는다. 쉼표를 없앤 뒤 변환한다.

```javascript
console.log(Number('1,234'));                       // NaN
console.log(parseInt('1,234'));                     // 1
console.log(Number('1,234'.replace(/,/g, '')));     // 1234
```

### 빈 문자열

`Number` 는 `0` 으로 변환한다. 입력하지 않은 값이 `0` 으로 처리된다.

```javascript
console.log(Number(''));        // 0
console.log(parseInt(''));      // NaN
```

## NaN

"숫자가 아님"을 나타내는 number 타입의 값이다. 숫자로 바꿀 수 없는 값을 변환하거나 결과를 숫자로 나타낼 수 없는 계산을 하면 나온다.

### 전파

`NaN` 이 들어간 계산의 결과는 `NaN` 이다. 에러가 나지 않고 끝까지 `NaN` 으로 이어진다.

```javascript
const qty = Number('abc');

console.log(qty);           // NaN
console.log(qty * 100);     // NaN
console.log(qty * 100 + 5); // NaN
```

### 비교

자기 자신과도 같지 않다. `=== NaN` 으로는 확인할 수 없다.

```javascript
console.log(NaN === NaN);   // false
```

### isNaN, Number.isNaN 의 차이

`isNaN` 은 값을 숫자로 변환한 뒤 검사하고, `Number.isNaN` 은 변환 없이 값이 `NaN` 그 자체인지만 검사한다.

| 값 | `isNaN` | `Number.isNaN` |
| --- | --- | --- |
| `NaN` | `true` | `true` |
| `'abc'` | `true` | `false` |
| `undefined` | `true` | `false` |
| `''` | `false` | `false` |
| `'12'` | `false` | `false` |

## 소수점 오차

소수 계산의 결과가 기대한 값과 조금 다르게 나오는 것이다. number 는 숫자를 2진수로 저장하는데, `0.1` 처럼 2진수로 정확히 표현할 수 없는 소수는 가장 가까운 값으로 저장되기 때문이다.

### 발생하는 계산

덧셈, 곱셈, 나눗셈 모두에서 생긴다.

```javascript
console.log(0.1 + 0.2);     // 0.30000000000000004
console.log(0.57 * 100);    // 56.99999999999999
console.log(100 * 1.1);     // 110.00000000000001
console.log(0.3 / 0.1);     // 2.9999999999999996
```

### 비교

오차가 있는 값은 `===` 로 비교하면 `false` 다.

```javascript
console.log(0.1 + 0.2 === 0.3);     // false
```

### 정수 계산

안전한 정수 범위 안의 정수끼리 더하고 빼고 곱하는 계산에는 오차가 없다. 소수를 정수로 바꿔 계산한 뒤 되돌리면 오차를 피할 수 있다.

```javascript
console.log((0.1 * 10 + 0.2 * 10) / 10);    // 0.3
```

## 반올림, 내림, 올림

`Math.round`, `Math.floor`, `Math.ceil` 은 정수를 돌려준다.

| 값 | `Math.round` | `Math.floor` | `Math.ceil` |
| --- | --- | --- | --- |
| `1.4` | `1` | `1` | `2` |
| `1.5` | `2` | `1` | `2` |
| `-1.5` | `-1` | `-2` | `-1` |
| `-1.6` | `-2` | `-2` | `-1` |

### 음수

`Math.round` 는 `.5` 를 큰 쪽으로 보낸다. `-1.5` 는 `-2` 가 아니라 `-1` 이다. `Math.floor` 는 0 쪽이 아니라 작은 쪽으로 간다.

### 자릿수 지정

원하는 자리가 소수 첫째 자리에 오도록 곱하거나 나눈 뒤, 반올림하고 되돌린다.

```javascript
console.log(Math.round(1234.567 * 100) / 100);  // 1234.57  (소수 둘째 자리까지)
console.log(Math.round(1234.567 / 10) * 10);    // 1230     (십의 자리까지)
```

### 자릿수 반올림의 오차

곱하는 단계에서 소수점 오차가 생기면 반올림 결과가 달라진다.

```javascript
console.log(1.005 * 100);                       // 100.49999999999999
console.log(Math.round(1.005 * 100) / 100);     // 1     (1.01 이 아니다)
console.log(Math.round(1.255 * 100) / 100);     // 1.25  (1.26 이 아니다)
```

## toFixed

`숫자.toFixed(자릿수)` 는 소수점 아래를 지정한 자릿수로 맞춘 문자열을 돌려준다.

### 반환값

숫자가 아니라 문자열이다. 그대로 `+` 를 쓰면 문자열 연결이 된다.

```javascript
const amt = (1234.567).toFixed(2);

console.log(amt);               // '1234.57'
console.log(amt + 1);           // '1234.571'
console.log(Number(amt) + 1);   // 1235.57
```

### 반올림 오차

저장된 값이 표기한 값보다 조금 작으면 내려간다.

```javascript
console.log((1.005).toFixed(2));    // '1.00'
console.log((2.675).toFixed(2));    // '2.67'
```

## Math.max, Math.min

### 배열

배열을 그대로 넘기면 `NaN` 이다. 스프레드로 펼쳐서 넘긴다.

```javascript
console.log(Math.max([1, 5, 3]));       // NaN
console.log(Math.max(...[1, 5, 3]));    // 5
```

### 인자가 없을 때

`Math.max` 는 `-Infinity`, `Math.min` 은 `Infinity` 다. 빈 배열을 펼쳐 넘기면 이 값이 나온다.

```javascript
console.log(Math.max(...[]));   // -Infinity
console.log(Math.min(...[]));   // Infinity
```

## 정리

- number: 정수와 실수를 구분하지 않는다. 0 으로 나눠도 에러가 나지 않는다.
- `Number`: 문자열 전체가 숫자여야 변환한다. 빈 문자열은 `0` 이다.
- `parseInt`: 앞에서부터 읽을 수 있는 데까지 읽어 정수로 변환한다.
- `NaN`: 계산에 들어가면 결과도 `NaN` 이다. 자기 자신과도 같지 않다.
- 소수점 오차: 2진수로 정확히 표현할 수 없는 소수 때문에 생긴다. `===` 비교와 반올림 결과에 영향을 준다.
- `Math.round`, `Math.floor`, `Math.ceil`: 정수를 돌려준다. 음수에서 방향이 다르다.
- `toFixed`, `toLocaleString`: 문자열을 돌려준다.
- `Math.max`, `Math.min`: 배열은 스프레드로 펼쳐 넘긴다.
