## 함수

함수는 실행할 코드를 담은 값이다. 숫자나 문자열처럼 변수에 담고, 다른 함수에 넘기고, 함수의 결과로 돌려줄 수 있다.

```javascript
const add = (a, b) => a + b;

console.log(typeof add);    // 'function'
console.log(add(1, 2));     // 3
```

---

## 선언 형태

함수를 만드는 문법은 세 가지다.

| 형태 | 모양 | 선언 전 호출 | 자기 `this` |
| --- | --- | --- | --- |
| 함수 선언문 | `function add(a, b) { }` | 가능 | 있음 |
| 함수 표현식 | `const add = function (a, b) { };` | 불가 | 있음 |
| 화살표 함수 | `const add = (a, b) => { };` | 불가 | 없음 |

### 선언 전 호출

함수 선언문만 선언한 줄보다 위에서 호출할 수 있다. 나머지는 변수에 함수를 담는 것이므로 변수의 규칙을 따른다.

```javascript
console.log(add(1, 2));     // 3
function add(a, b) {
    return a + b;
}
```

```javascript
console.log(sub(3, 1));     // ReferenceError: Cannot access 'sub' before initialization
const sub = (a, b) => a - b;
```

### this

화살표 함수는 자기 `this` 가 없다. 4-4 "this와 bind"에서 다룬다.

---

## 화살표 함수

### 본문

`{ }` 없이 식 하나를 적으면 그 식의 결과를 돌려준다. `{ }` 를 쓰면 `return` 을 적어야 한다.

```javascript
const a = (x) => x * 2;
const b = (x) => { return x * 2; };
const c = (x) => { x * 2; };

console.log(a(2));  // 4
console.log(b(2));  // 4
console.log(c(2));  // undefined
```

### 객체 반환

객체를 돌려줄 때는 `( )` 로 감싼다. 감싸지 않으면 `{ }` 가 함수의 본문으로 읽힌다.

```javascript
const a = (v) => { value: v };
const b = (v) => ({ value: v });

console.log(a(1));  // undefined
console.log(b(1));  // { value: 1 }
```

### new

화살표 함수는 `new` 로 호출할 수 없다.

```javascript
const A = () => {};
new A();    // TypeError: A is not a constructor
```

## 함수를 담는 자리

함수는 값이므로 값을 둘 수 있는 자리면 어디든 담을 수 있다. 문법이 달라 보여도 전부 함수를 어딘가에 넣는 것이다.

| 자리 | 모양 | 호출 |
| --- | --- | --- |
| 변수 | `const save = () => { };` | `save()` |
| 객체의 속성 | `{ save: () => { } }` | `객체.save()` |
| 객체의 속성 (축약) | `{ save() { } }` | `객체.save()` |
| 클래스의 메서드 | `class A { save() { } }` | `this.save()` |
| 클래스의 필드 | `class A { save = () => { }; }` | `this.save()` |
| 인자 | `rows.map((r) => r.id)` | 받은 쪽이 호출한다 |

`{ save() { } }` 는 `{ save: function () { } }` 를 줄여 쓴 것이다.

## 인자

### 개수

매개변수의 개수와 인자의 개수가 달라도 에러가 나지 않는다. 모자란 매개변수는 `undefined` 가 되고, 남는 인자는 버려진다.

```javascript
const f = (a, b) => [a, b];

console.log(f(1));          // [1, undefined]
console.log(f(1, 2, 3));    // [1, 2]
```

---

## 반환값

### return 이 없을 때

`undefined` 를 돌려준다.

```javascript
const f = () => {};

console.log(f());   // undefined
```

### return 뒤의 줄바꿈

`return` 바로 뒤에서 줄을 바꾸면 그 자리에서 문장이 끝난다. 아랫줄의 값은 돌려주지 않는다.

```javascript
const f = () => {
    return
        1;
};

console.log(f());   // undefined
```

여러 줄을 돌려줄 때는 `return (` 으로 괄호를 같은 줄에서 연다.

---

## 정리

- 함수: 실행할 코드를 담은 값. 변수에 담고 넘기고 돌려줄 수 있다.
- 함수 선언문: 선언한 줄보다 위에서 호출할 수 있다.
- 화살표 함수: `{ }` 를 쓰면 `return` 이 필요하다. 객체를 돌려줄 때는 `( )` 로 감싼다. 자기 `this` 가 없다.
- 함수를 담는 자리: 변수, 객체의 속성, 클래스의 메서드와 필드, 인자.
- 인자: 개수가 맞지 않아도 에러가 나지 않는다.
- 반환값: `return` 이 없으면 `undefined` 다.
