## Promise

Promise 는 나중에 정해질 결과를 나타내는 객체다. 시간이 걸리는 함수는 결과 대신 Promise 를 바로 돌려주고, 결과는 나중에 그 Promise 에 들어온다.

### 상태

| 상태 | 뜻 | 갖고 있는 것 |
| --- | --- | --- |
| pending | 아직 결과가 정해지지 않았다 | 없음 |
| fulfilled | 성공했다 | 결과 값 |
| rejected | 실패했다 | 실패 이유 (보통 Error 객체) |

pending 에서 fulfilled 또는 rejected 로 한 번만 바뀐다. 한 번 정해지면 다시 바뀌지 않는다.

### 결과를 바로 읽을 수 없다

Promise 는 결과가 아니라 결과가 들어올 객체다. 값처럼 쓰면 에러 없이 틀린 결과가 나온다.

```javascript
const p = getCount();   // Promise 를 돌려주는 함수

console.log(p + 1);                 // '[object Promise]1'
console.log(p ? '참' : '거짓');     // '참'  (객체이므로 항상 참 같은 값이다)
console.log(JSON.stringify(p));     // '{}'
```

결과를 꺼내는 방법은 `then` 과 `await` 다.

## then

`promise.then(함수)` 는 Promise 가 성공하면 실행할 함수를 등록한다. 함수는 결과 값을 인자로 받는다.

```javascript
getCount().then((count) => {
    console.log(count);
});
```

### 실행 시점

등록한 함수는 지금 실행 중인 코드가 끝난 뒤에 실행된다. Promise 가 이미 성공한 상태여도 마찬가지다.

```javascript
const order = [];

Promise.resolve().then(() => order.push('then'));
order.push('동기');

// 이후: ['동기', 'then']
```

### 반환값

`then` 은 새 Promise 를 돌려준다. 그래서 `then` 을 이어 쓸 수 있다. 새 Promise 의 결과는 등록한 함수가 돌려준 값이다.

| 등록한 함수가 돌려준 것 | 새 Promise 의 결과 |
| --- | --- |
| 값 | 그 값 |
| 없음 | `undefined` |
| Promise | 그 Promise 의 결과 |
| 에러를 던짐 | 실패 |

```javascript
Promise.resolve(1)
    .then((v) => v + 1)         // 2
    .then((v) => v * 10)        // 20
    .then((v) => { v + 1; })    // return 이 없다 → undefined
    .then((v) => console.log(v));   // undefined
```

## catch

`promise.catch(함수)` 는 Promise 가 실패하면 실행할 함수를 등록한다. 함수는 실패 이유를 인자로 받는다.

### 건너뛰는 then

실패하면 `catch` 를 만날 때까지 그 사이의 `then` 은 실행되지 않는다.

```javascript
Promise.reject(new Error('실패'))
    .then(() => console.log('실행되지 않는다'))
    .catch((e) => console.log('잡음: ' + e.message));   // '잡음: 실패'
```

### then 안의 에러

`then` 에 등록한 함수 안에서 에러가 던져지면 뒤의 `catch` 로 간다.

```javascript
Promise.resolve(1)
    .then(() => { throw new Error('then 안의 에러'); })
    .catch((e) => console.log(e.message));  // 'then 안의 에러'
```

### catch 뒤

`catch` 도 새 Promise 를 돌려준다. `catch` 의 함수가 값을 돌려주면 성공한 것으로 이어져서 뒤의 `then` 이 실행된다.

```javascript
Promise.reject(new Error('실패'))
    .catch(() => '기본값')
    .then((v) => console.log(v));   // '기본값'
```

---

## finally

`promise.finally(함수)` 는 성공하든 실패하든 실행할 함수를 등록한다. 함수는 인자를 받지 않고, 돌려준 값은 무시된다. 원래의 결과가 그대로 다음으로 넘어간다.

```javascript
Promise.resolve('결과')
    .finally(() => '무시되는 값')
    .then((v) => console.log(v));   // '결과'
```

## new Promise

`new Promise((resolve, reject) => { })` 로 Promise 를 직접 만든다. `resolve(값)` 을 호출하면 성공, `reject(이유)` 를 호출하면 실패가 된다.

```javascript
const wait = (ms) => new Promise((resolve) => {
    setTimeout(resolve, ms);
});
```

### 넘긴 함수의 실행 시점

`new Promise` 에 넘긴 함수는 그 자리에서 바로 실행된다.

```javascript
const order = [];

new Promise((resolve) => {
    order.push('넘긴 함수');
    resolve();
});
order.push('new Promise 다음 줄');

// order: ['넘긴 함수', 'new Promise 다음 줄']
```

### resolve, reject 의 호출

처음 한 번만 효과가 있다. 그 뒤의 호출은 무시된다.

```javascript
const p = new Promise((resolve, reject) => {
    resolve(1);
    resolve(2);                 // 무시된다
    reject(new Error('실패'));  // 무시된다
});

p.then((v) => console.log(v));  // 1
```

`resolve` 를 호출해도 함수는 끝나지 않는다. 그 아래 줄도 실행된다. 끝내려면 `return` 을 쓴다.

### 넘긴 함수 안의 에러

에러가 던져지면 Promise 가 실패 상태가 된다.

```javascript
new Promise(() => {
    throw new Error('에러');
}).catch((e) => console.log(e.message));    // '에러'
```

### 호출하지 않았을 때

`resolve` 도 `reject` 도 호출하지 않으면 Promise 는 계속 pending 이다. `then` 도 `catch` 도 실행되지 않고, 에러도 나지 않는다.

---

## then, catch, finally 비교

| | 실행되는 때 | 받는 인자 | 돌려준 값 |
| --- | --- | --- | --- |
| `then` | 성공했을 때 | 결과 값 | 다음으로 넘어간다 |
| `catch` | 실패했을 때 | 실패 이유 | 다음으로 넘어간다 (성공으로 바뀐다) |
| `finally` | 항상 | 없음 | 무시된다 |

---

## 정리

- Promise: 나중에 정해질 결과를 나타내는 객체. 상태는 pending, fulfilled, rejected 다.
- Promise 는 결과가 아니다. 값처럼 쓰면 에러 없이 틀린 결과가 나온다.
- `then`: 성공하면 실행할 함수를 등록한다. 새 Promise 를 돌려주고, 등록한 함수가 돌려준 값이 그 결과가 된다.
- `catch`: 실패하면 실행할 함수를 등록한다. 값을 돌려주면 성공으로 이어진다.
- `new Promise`: 넘긴 함수는 바로 실행된다. `resolve`, `reject` 는 처음 한 번만 효과가 있다.
- `resolve` 도 `reject` 도 호출하지 않으면 계속 pending 이다.
