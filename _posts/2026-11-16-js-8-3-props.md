## props

props 는 부모 컴포넌트가 자식 컴포넌트에 넘기는 값이다. 태그의 속성으로 넘기고, 자식은 `this.props` 로 읽는다.

```jsx
// 부모
<Child title="제목" count={3} />

// 자식
class Child extends React.Component {
    render() {
        return <div>{this.props.title} {this.props.count}</div>;
    }
}
```

### 읽기 전용

자식은 props 를 바꿀 수 없다.

```javascript
this.props.title = '다른 제목';
// TypeError: Cannot assign to read only property 'title' of object '#<Object>'
```

### defaultProps

props 를 넘기지 않았을 때 쓸 기본값이다. 값이 `undefined` 일 때만 적용된다. `null` 을 넘기면 적용되지 않는다.

```javascript
Child.defaultProps = { title: '기본 제목' };
```

| 넘긴 값 | `this.props.title` |
| --- | --- |
| 넘기지 않음 | `'기본 제목'` |
| `undefined` | `'기본 제목'` |
| `null` | `null` |

### children

여는 태그와 닫는 태그 사이에 적은 내용은 `this.props.children` 으로 들어온다.

```jsx
<Panel>내용</Panel>

// Panel 안에서
this.props.children     // '내용'
```

## 부모에서 자식으로

값을 props 로 넘긴다. 부모의 state 가 바뀌면 부모가 다시 그려지면서 자식에 새 props 가 넘어간다.

```jsx
class Parent extends React.Component {
    state = { step: '1' };

    render() {
        return <Child step={this.state.step} />;
    }
}
```

---

## 자식에서 부모로

자식은 부모의 state 를 직접 바꿀 수 없다. 부모가 state 를 바꾸는 함수를 props 로 넘기고, 자식이 그 함수를 호출한다.

```jsx
class Parent extends React.Component {
    state = { step: '1' };

    onChangeStep = (step) => {
        this.setState({ step });
    };

    render() {
        return <Child step={this.state.step} onChangeStep={this.onChangeStep} />;
    }
}

class Child extends React.Component {
    render() {
        return <button onClick={() => this.props.onChangeStep('2')}>다음</button>;
    }
}
```

1. 자식의 버튼을 누르면 `this.props.onChangeStep('2')` 가 호출된다.
2. 그 함수는 부모의 것이므로 부모의 `setState` 가 실행된다.
3. 부모가 다시 그려지고, 자식에 새 `step` 이 넘어간다.

---

## 부모가 다시 그려질 때

부모의 `render` 가 다시 호출되면 그 안의 자식들도 다시 그려진다. 자식에 넘긴 props 가 이전과 같아도 다시 그려진다.

```jsx
class Parent extends React.Component {
    state = { count: 0 };

    render() {
        // count 가 바뀌면 Child 도 다시 그려진다. title 은 그대로인데도.
        return <Child title="제목" />;
    }
}
```

---

## props 를 state 로 복사

자식이 props 의 값을 자기 state 의 초기값으로 넣으면, 그 값은 처음 만들어질 때 한 번만 복사된다. 나중에 props 가 바뀌어도 state 는 바뀌지 않는다.

```jsx
class Child extends React.Component {
    state = { qty: this.props.qty };    // 처음 한 번만 실행된다

    render() {
        return <div>props={this.props.qty} state={this.state.qty}</div>;
    }
}
```

부모가 `qty` 를 1 에서 2 로 바꾸면 화면은 `props=2 state=1` 이 된다.

---

## props, state 비교

| | props | state |
| --- | --- | --- |
| 값을 정하는 쪽 | 부모 | 자기 자신 |
| 읽기 | `this.props.이름` | `this.state.이름` |
| 바꾸기 | 불가 | `this.setState` |
| 바뀌면 | 다시 그려진다 | 다시 그려진다 |

---

## 정리

- props: 부모가 자식에 넘기는 값. 자식은 바꿀 수 없다.
- `defaultProps`: 값이 `undefined` 일 때만 적용된다.
- 부모에서 자식으로는 props 로 값을 넘긴다.
- 자식에서 부모로는 부모가 넘긴 함수를 자식이 호출한다.
- 부모가 다시 그려지면 자식도 다시 그려진다.
- props 를 state 의 초기값으로 복사하면 나중에 props 가 바뀌어도 state 는 그대로다.
