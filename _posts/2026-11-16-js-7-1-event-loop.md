## 단일 스레드

JS 코드를 실행하는 스레드는 하나다. 한 번에 함수 하나만 실행한다.

### 끼어들 수 없는 실행

실행 중인 코드는 끝날 때까지 멈추지 않는다. 그동안 다른 코드는 실행되지 않는다. 타이머가 만료되거나 버튼이 눌려도 지금 코드가 끝난 뒤에 처리된다.

### 오래 걸리는 코드

스레드를 붙잡고 있는 동안 화면의 모든 동작이 멈춘다. 클릭 처리, 화면 다시 그리기, 타이머가 전부 기다린다.

```javascript
const order = [];

setTimeout(() => order.push('타이머 10ms'), 10);

const start = Date.now();
while (Date.now() - start < 100) { }    // 100ms 동안 스레드를 붙잡는다
order.push('반복문 끝');

// 이후: ['반복문 끝', '타이머 10ms']
```

타이머는 10ms 뒤에 만료됐지만 100ms 뒤에야 실행된다.

## 태스크 큐

태스크 큐는 나중에 실행할 콜백이 순서대로 쌓이는 곳이다.

### 들어오는 것

| 일어난 일 | 큐에 들어가는 것 |
| --- | --- |
| 타이머 만료 | `setTimeout` 에 넘긴 함수 |
| 클릭, 입력 | 이벤트에 연결한 함수 |
| 서버 응답 도착 | 응답을 처리할 함수 |

### 기다리는 주체

시간을 재거나 서버 응답을 기다리는 것은 JS 스레드가 아니라 브라우저다. 브라우저가 기다리는 동안 JS 스레드는 다른 코드를 실행한다. 기다리던 일이 끝나면 브라우저가 콜백을 큐에 넣는다.

---

## 이벤트 루프

이벤트 루프는 실행 중인 코드가 없을 때 큐에서 콜백을 하나 꺼내 실행하는 것을 반복하는 구조다.

### 순서

1. 지금 실행 중인 코드를 끝까지 실행한다.
2. 마이크로태스크 큐에 있는 것을 전부 실행한다.
3. 필요하면 화면을 다시 그린다.
4. 태스크 큐에서 하나를 꺼내 실행하고, 2번으로 돌아간다.

---

## setTimeout

`setTimeout(함수, 밀리초)` 는 지정한 시간이 지나면 함수를 태스크 큐에 넣어 달라고 맡긴다. 맡기기만 하고 바로 다음 줄로 넘어간다.

### 0 밀리초

바로 실행되지 않는다. 지금 실행 중인 코드가 끝난 뒤에 실행된다.

```javascript
const order = [];

order.push('A');
setTimeout(() => order.push('C'), 0);
order.push('B');

// 이후: ['A', 'B', 'C']
```

### 지정한 시간

그 시간에 실행된다는 뜻이 아니라 그 시간이 지나야 큐에 들어간다는 뜻이다. 스레드가 다른 코드를 실행 중이면 더 늦어진다.

### 취소

`setTimeout` 은 타이머의 식별값을 돌려준다. `clearTimeout(식별값)` 으로 실행 전에 취소한다.

```javascript
const id = setTimeout(() => console.log('실행되지 않는다'), 1000);
clearTimeout(id);
```

## 마이크로태스크 큐

마이크로태스크 큐는 Promise 의 `then` 에 넘긴 함수와 `await` 뒤의 코드가 들어가는 큐다. 태스크 큐보다 먼저 처리된다.

### 순서

지금 코드가 끝나면 마이크로태스크를 전부 실행하고, 그다음에 태스크를 실행한다.

```javascript
const order = [];

order.push('1 동기');
setTimeout(() => order.push('4 타이머'), 0);
Promise.resolve().then(() => order.push('3 then'));
order.push('2 동기');

// 이후: ['1 동기', '2 동기', '3 then', '4 타이머']
```

### 실행 중에 추가된 마이크로태스크

마이크로태스크를 실행하다가 새로 추가된 마이크로태스크도 태스크보다 먼저 실행된다.

```javascript
const order = [];

setTimeout(() => order.push('타이머'), 0);
Promise.resolve().then(() => {
    order.push('then 1');
    Promise.resolve().then(() => order.push('then 1 안에서 추가'));
});
Promise.resolve().then(() => order.push('then 2'));

// 이후: ['then 1', 'then 2', 'then 1 안에서 추가', '타이머']
```

## 태스크, 마이크로태스크 비교

| | 태스크 | 마이크로태스크 |
| --- | --- | --- |
| 들어오는 것 | 타이머, 이벤트, 서버 응답 | `then` 의 함수, `await` 뒤의 코드 |
| 실행되는 때 | 마이크로태스크 큐가 빈 뒤에 하나씩 | 지금 코드가 끝난 직후에 전부 |
| 우선순위 | 뒤 | 앞 |

---

## 정리

- 단일 스레드: 한 번에 함수 하나만 실행한다. 실행 중인 코드는 끝날 때까지 멈추지 않는다.
- 스레드를 붙잡고 있으면 클릭, 타이머, 화면 그리기가 모두 기다린다.
- 태스크 큐: 타이머, 이벤트, 서버 응답의 콜백이 쌓이는 곳. 기다리는 것은 브라우저다.
- 이벤트 루프: 지금 코드 → 마이크로태스크 전부 → 태스크 하나 순서로 반복한다.
- `setTimeout(함수, 0)`: 지금 코드가 끝난 뒤에 실행된다.
- 마이크로태스크: `then` 의 함수와 `await` 뒤의 코드. 태스크보다 먼저 실행된다.
