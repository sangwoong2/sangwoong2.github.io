## 시작과 기다림

Promise 를 돌려주는 함수는 **호출하는 순간** 작업을 시작한다. `await` 는 작업을 시작시키는 것이 아니라, 이미 시작된 작업이 끝나기를 기다리는 것이다.

```javascript
const p = fetchItems();     // 여기서 조회가 시작된다
// ...
const items = await p;      // 여기서는 끝나기를 기다릴 뿐이다
```

---

## 순차 실행

앞의 작업이 끝난 뒤에 다음 작업을 시작하는 것이다. 걸리는 시간은 각 작업의 합이다.

```javascript
const items = await fetchItems();       // 1초
const partners = await fetchPartners(); // 1초
// 합계 약 2초
```

두 번째 줄은 첫 번째 줄의 `await` 가 끝난 뒤에야 실행되므로, 두 번째 조회는 1초 뒤에 시작된다.

---

## 병렬 실행

여러 작업을 먼저 모두 시작해 놓고, 그 뒤에 기다리는 것이다. 걸리는 시간은 가장 오래 걸리는 작업 하나만큼이다.

```javascript
const itemsPromise = fetchItems();          // 시작
const partnersPromise = fetchPartners();    // 시작

const items = await itemsPromise;
const partners = await partnersPromise;
// 합계 약 1초
```

---

## Promise.all

`Promise.all(Promise 의 배열)` 은 모두 성공하면 결과의 배열로 성공하는 Promise 를 돌려준다.

```javascript
const [items, partners] = await Promise.all([fetchItems(), fetchPartners()]);
```

### 결과의 순서

끝난 순서가 아니라 넘긴 순서다.

```javascript
const result = await Promise.all([wait(60, '느림'), wait(10, '빠름')]);

console.log(result);    // ['느림', '빠름']
```

### 하나가 실패했을 때

하나라도 실패하면 `Promise.all` 전체가 그 이유로 실패한다. 성공한 것의 결과도 받을 수 없다.

```javascript
try {
    await Promise.all([wait(10, 'ok'), fail(20, '실패'), wait(30, 'ok')]);
} catch (e) {
    console.log(e.message);     // '실패'
}
```

나머지 작업이 취소되는 것은 아니다. 이미 시작된 작업은 끝까지 실행되고, 결과만 버려진다.

### 빈 배열

빈 배열로 바로 성공한다.

```javascript
console.log(await Promise.all([]));     // []
```

### 배열을 병렬로 처리하기

`map` 으로 Promise 의 배열을 만들고 `Promise.all` 로 기다린다.

```javascript
const details = await Promise.all(rows.map((row) => fetchDetail(row.id)));
```

---

## Promise.allSettled

모두 끝날 때까지 기다리고, 각각의 성공 여부와 결과를 배열로 돌려준다. 실패가 있어도 전체가 실패하지 않는다.

```javascript
const results = await Promise.allSettled([wait(5, 'ok'), fail(5, '실패')]);

console.log(results[0]);    // { status: 'fulfilled', value: 'ok' }
console.log(results[1]);    // { status: 'rejected', reason: Error('실패') }
```

---

## Promise.race

가장 먼저 끝난 것의 결과로 끝난다. 성공이든 실패든 먼저 끝난 것을 따른다.

```javascript
console.log(await Promise.race([wait(50, '느림'), wait(10, '빠름')]));  // '빠름'
```

---

## all, allSettled, race 비교

| | 끝나는 때 | 성공했을 때의 결과 | 하나가 실패하면 |
| --- | --- | --- | --- |
| `Promise.all` | 모두 성공했을 때 | 결과의 배열 | 전체가 실패한다 |
| `Promise.allSettled` | 모두 끝났을 때 | `{ status, value 또는 reason }` 의 배열 | 실패하지 않는다 |
| `Promise.race` | 하나가 끝났을 때 | 먼저 끝난 것의 결과 | 그것이 먼저 끝났으면 실패한다 |

---

## 순차, 병렬의 선택

| 상황 | 방식 |
| --- | --- |
| 뒤의 작업이 앞의 결과를 쓴다 | 순차 |
| 순서가 지켜져야 한다 (저장 후 조회) | 순차 |
| 서로 관계없다 | 병렬 |

```javascript
// 순차: 저장이 끝난 뒤에 조회해야 한다
await save(row);
const rows = await fetchRows();

// 병렬: 두 조회는 서로 관계없다
const [items, partners] = await Promise.all([fetchItems(), fetchPartners()]);
```

---

## 정리

- Promise 를 돌려주는 함수는 호출하는 순간 작업을 시작한다. `await` 는 끝나기를 기다린다.
- 순차 실행: 한 줄씩 `await` 한다. 시간은 각 작업의 합이다.
- 병렬 실행: 먼저 모두 시작하고 나중에 기다린다. 시간은 가장 긴 작업만큼이다.
- `Promise.all`: 모두 성공하면 넘긴 순서대로 결과를 돌려준다. 하나라도 실패하면 전체가 실패한다.
- `Promise.allSettled`: 실패가 있어도 모두 끝날 때까지 기다린다.
- `Promise.race`: 가장 먼저 끝난 것을 따른다.
