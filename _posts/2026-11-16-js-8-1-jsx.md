## 컴포넌트

컴포넌트는 화면의 한 부분을 그리는 단위다. 클래스 컴포넌트는 `React.Component` 를 상속한 클래스이고, `render` 메서드가 돌려준 것이 화면에 그려진다.

```jsx
class Page extends React.Component {
    render() {
        return <div>화면</div>;
    }
}
```

---

## JSX

JSX 는 JS 코드 안에 태그 모양으로 화면을 적는 문법이다. 브라우저가 이해하는 문법이 아니라서, 빌드할 때 함수 호출로 바뀐다.

### 변환

태그 하나가 `React.createElement` 호출 하나로 바뀐다. 호출의 결과는 화면이 아니라 "무엇을 그릴지"를 적은 객체다. 이 객체를 React 요소라고 한다.

```jsx
const element = <div className="box">내용</div>;
```

```javascript
const element = React.createElement('div', { className: 'box' }, '내용');

console.log(typeof element);    // 'object'
console.log(element.props);     // { className: 'box', children: '내용' }
```

### 중괄호

`{ }` 안에는 JS 식을 적는다. 식의 결과가 그 자리에 들어간다. `if`, `for` 같은 문장은 적을 수 없다.

```jsx
<div>{count}건</div>
<div>{count > 0 ? '있음' : '없음'}</div>
```

### 속성

HTML 과 이름이 다른 것이 있다. 값이 문자열이 아니면 `{ }` 로 감싼다.

| HTML | JSX |
| --- | --- |
| `class` | `className` |
| `for` | `htmlFor` |
| `onclick` | `onClick` |
| `style="margin-left: 16px"` | `style` 에 객체를 넘긴다 |

`style` 에는 객체를 넘기므로 중괄호가 두 겹이 된다. 바깥은 JSX 의 `{ }` 이고 안쪽은 객체의 `{ }` 다.

{% raw %}
```jsx
<div style={{ marginLeft: 16, color: 'red' }}>내용</div>
```
{% endraw %}

### 태그 이름

소문자로 시작하면 HTML 태그, 대문자로 시작하면 컴포넌트다.

```jsx
<div />         // HTML 의 div
<OBTButton />   // OBTButton 컴포넌트
```

### 하나로 감싸기

`render` 는 요소 하나를 돌려줘야 한다. 여러 요소를 돌려주려면 하나로 감싼다. `<> </>` 는 화면에 태그를 남기지 않고 감싸는 문법이다.

```jsx
render() {
    return (
        <>
            <h1>제목</h1>
            <p>내용</p>
        </>
    );
}
```

## 화면에 나오지 않는 값

`{ }` 안의 값에 따라 화면에 나오는 것이 다르다.

| 값 | 화면 |
| --- | --- |
| `false`, `true`, `null`, `undefined` | 아무것도 나오지 않는다 |
| `''` | 아무것도 나오지 않는다 |
| `0` | `0` 이 나온다 |
| 문자열, 숫자 | 그대로 나온다 |
| 배열 | 요소가 차례로 나온다 |
| 객체 | 에러가 난다 |

### 객체

객체를 그대로 넣으면 에러가 난다. 속성을 꺼내서 넣어야 한다.

```jsx
<div>{user}</div>           // Error: Objects are not valid as a React child
<div>{user.name}</div>
```

## 조건부 렌더링

### &&

왼쪽이 참 같은 값이면 오른쪽 요소가 그려진다. 왼쪽이 `false`, `null`, `undefined` 면 아무것도 그려지지 않는다.

```jsx
{isLoggedIn && <UserInfo />}
```

### && 와 0

왼쪽이 `0` 이면 `0` 이 화면에 나온다. `&&` 는 왼쪽 값을 그대로 돌려주고, `0` 은 화면에 나오는 값이기 때문이다. 조건을 불리언으로 만들어야 한다.

```jsx
{rows.length && <Grid />}       // rows 가 비어 있으면 화면에 0 이 나온다
{rows.length > 0 && <Grid />}   // 아무것도 나오지 않는다
```

### 삼항 연산자

둘 중 하나를 그린다.

```jsx
{isLoggedIn ? <UserInfo /> : <LoginButton />}
```

## 목록 렌더링

배열을 `map` 으로 요소의 배열로 바꿔서 넣는다.

```jsx
<ul>
    {rows.map((row) => (
        <li key={row.id}>{row.name}</li>
    ))}
</ul>
```

### key

`key` 는 목록의 요소를 서로 구분하는 값이다. React 는 다시 그릴 때 `key` 가 같은 것을 같은 요소로 본다. 없으면 경고가 나온다.

```
Warning: Each child in a list should have a unique "key" prop.
```

### 인덱스를 key 로 쓸 때

순서가 바뀌거나 중간이 삭제되면 `key` 가 다른 데이터를 가리키게 된다. 요소가 갖고 있던 state 가 다른 데이터에 붙는다.

아래는 각 행이 자기 메모를 state 로 갖고 있을 때, 순서를 A, B 에서 B, A 로 바꾼 결과다.

| key | 순서를 바꾼 뒤 |
| --- | --- |
| 인덱스 | B 행에 A 의 메모, A 행에 B 의 메모 |
| 데이터의 id | B 행에 B 의 메모, A 행에 A 의 메모 |

## render 의 반환값

### return 누락

아무것도 돌려주지 않으면 에러가 난다.

```
Error: Page(...): Nothing was returned from render. This usually means a return statement is missing.
```

### null

`null` 을 돌려주면 아무것도 그리지 않는다.

```jsx
render() {
    if (!this.props.visible) return null;
    return <div>내용</div>;
}
```

---

## 정리

- 컴포넌트: 화면의 한 부분을 그리는 단위. `render` 가 돌려준 것이 그려진다.
- JSX: 태그 모양의 문법. `React.createElement` 호출로 바뀌고, 결과는 React 요소라는 객체다.
- `{ }` 안에는 식을 적는다. `false`, `null`, `undefined` 는 화면에 나오지 않고 `0` 은 나온다.
- `&&` 의 왼쪽이 `0` 이면 `0` 이 화면에 나온다.
- 목록은 `map` 으로 그리고 `key` 로 요소를 구분한다. 인덱스를 `key` 로 쓰면 순서가 바뀔 때 state 가 엇갈린다.
- `render` 는 반드시 값을 돌려줘야 한다. 그리지 않으려면 `null` 을 돌려준다.
