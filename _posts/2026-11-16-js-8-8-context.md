## context

context 는 중간의 컴포넌트들을 거치지 않고 아래쪽 컴포넌트에 값을 전달하는 방법이다. props 로는 부모에서 자식으로 한 단계씩 넘겨야 하는데, context 는 위에서 값을 내놓으면 아래 어디서든 꺼내 쓸 수 있다.

### 구성

| 구성 | 하는 일 |
| --- | --- |
| `React.createContext(기본값)` | context 를 만든다 |
| `<Context.Provider value={값}>` | 이 안쪽의 컴포넌트들에 값을 내놓는다 |
| `static contextType = Context` | 클래스 컴포넌트에서 쓸 context 를 지정한다 |
| `this.context` | 지정한 context 의 값을 읽는다 |

```jsx
const LayoutContext = React.createContext(null);

class Layout extends React.Component {
    setSnackbar = (message) => { /* ... */ };

    render() {
        return (
            <LayoutContext.Provider value={this.value}>
                {this.props.children}
            </LayoutContext.Provider>
        );
    }
}

class Page extends React.Component {
    static contextType = LayoutContext;

    onClick = () => {
        this.context.setSnackbar('저장되었습니다.');
    };
}
```

`Page` 가 `Layout` 의 몇 단계 아래에 있든 `this.context` 로 값을 읽는다.

## 값을 찾는 방식

### 가장 가까운 Provider

컴포넌트에서 위쪽으로 올라가며 처음 만나는 Provider 의 값을 쓴다.

### Provider 가 없을 때

위쪽에 Provider 가 없으면 `createContext` 에 넘긴 기본값이 나온다. 에러가 나지 않는다.

```jsx
const Context = React.createContext('기본값');

// Provider 없이 쓰면 this.context 는 '기본값'
```

### contextType 을 지정하지 않았을 때

`this.context` 는 빈 객체다. 에러가 나지 않고, 속성을 읽으면 `undefined` 다.

```jsx
class Page extends React.Component {
    // static contextType 이 없다

    onClick = () => {
        this.context.setSnackbar('저장');   // TypeError: this.context.setSnackbar is not a function
    };
}
```

## 값이 바뀔 때

Provider 의 `value` 가 바뀌면 그 context 를 쓰는 컴포넌트가 다시 그려진다.

### 중간의 PureComponent

중간에 다시 그리지 않는 PureComponent 가 있어도, 그 아래에서 context 를 쓰는 컴포넌트는 다시 그려진다. context 의 변경은 props 를 거치지 않고 전달된다.

### 매번 새 객체를 넘길 때

`value` 가 바뀌었는지는 참조로 비교한다. `render` 안에서 객체를 새로 만들어 넘기면 그릴 때마다 값이 바뀐 것으로 처리되어, 그 context 를 쓰는 컴포넌트가 전부 다시 그려진다.

{% raw %}
```jsx
render() {
    return (
        <Context.Provider value={{ setAlert: this.setAlert }}>
            {this.props.children}
        </Context.Provider>
    );
}
```
{% endraw %}

필드에 담아 둔 객체를 넘기면 참조가 유지된다.

```jsx
value = { setAlert: this.setAlert };

render() {
    return (
        <Context.Provider value={this.value}>
            {this.props.children}
        </Context.Provider>
    );
}
```

## Consumer

`contextType` 대신 쓸 수 있는 방식이다. 태그 안에 함수를 적으면 그 함수가 context 의 값을 인자로 받는다. 한 컴포넌트에서 여러 context 를 쓸 때 쓴다.

```jsx
<Context.Consumer>
    {(value) => <div>{value}</div>}
</Context.Consumer>
```

## props, context 비교

| | props | context |
| --- | --- | --- |
| 전달 경로 | 부모에서 자식으로 한 단계씩 | Provider 아래 어디서든 |
| 읽기 | `this.props.이름` | `this.context` |
| 값의 출처 | 태그의 속성에 보인다 | 위쪽 어딘가의 Provider |
| 쓰는 경우 | 그 컴포넌트에 필요한 데이터 | 여러 화면이 함께 쓰는 기능 (알림, 로그인 정보) |

---

## 정리

- context: 중간 컴포넌트를 거치지 않고 아래쪽에 값을 전달한다.
- Provider 가 값을 내놓고, `static contextType` 을 지정한 컴포넌트가 `this.context` 로 읽는다.
- Provider 가 없으면 기본값이 나온다. `contextType` 을 지정하지 않으면 `this.context` 는 빈 객체다.
- `value` 가 바뀌면 그 context 를 쓰는 컴포넌트가 다시 그려진다. 중간의 PureComponent 와 관계없다.
- `value` 에 매번 새 객체를 넘기면 그릴 때마다 전부 다시 그려진다.
