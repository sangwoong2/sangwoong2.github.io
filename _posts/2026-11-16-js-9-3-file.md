## 브라우저와 파일

브라우저의 JS 는 사용자 PC 의 파일에 직접 접근할 수 없다. 읽을 수 있는 것은 사용자가 직접 고른 파일뿐이고, 저장은 다운로드로만 할 수 있다.

| 하려는 일 | 방법 |
| --- | --- |
| 파일 읽기 | 사용자가 파일 선택 창에서 고른 파일을 읽는다 |
| 파일 저장 | 데이터를 만들어 다운로드시킨다 |

---

## Blob

Blob 은 파일의 내용에 해당하는 데이터 덩어리를 나타내는 객체다. 문자열이나 이진 데이터를 담는다.

```javascript
const blob = new Blob(['abc'], { type: 'text/plain' });

console.log(blob.size);     // 3  (바이트)
console.log(blob.type);     // 'text/plain'
```

### 만드는 방법

`new Blob(배열, 옵션)` 이다. 첫 인자는 내용을 담은 배열이다. 내용 하나만 넣어도 배열로 감싼다.

```javascript
new Blob([data]);       // data 를 배열로 감싼다
```

### File

File 은 이름과 수정 시각이 붙은 Blob 이다. 사용자가 고른 파일이 File 객체로 들어온다.

---

## 파일 저장

브라우저에는 "이 데이터를 이 이름으로 저장하라"는 직접적인 함수가 없다. Blob 을 가리키는 임시 주소를 만들고, 그 주소로 가는 링크를 클릭하는 방식으로 다운로드시킨다.

### 순서

1. 저장할 내용으로 Blob 을 만든다.
2. `URL.createObjectURL(blob)` 으로 그 Blob 을 가리키는 임시 주소를 만든다.
3. `download` 속성이 있는 링크를 만들어 클릭한다.
4. `URL.revokeObjectURL(주소)` 로 임시 주소를 해제한다.

```javascript
const url = URL.createObjectURL(blob);
const link = document.createElement('a');

link.href = url;
link.download = '파일이름.txt';
link.click();

URL.revokeObjectURL(url);
```

### 저장 라이브러리

위 과정을 대신 해 주는 함수를 쓰는 경우가 많다.

```javascript
import { saveAs } from 'file-saver';

saveAs(blob, '파일이름.xlsx');
```

## 엑셀 파일 만들기

엑셀 파일의 내용을 JS 로 만든 뒤 Blob 으로 감싸서 저장한다.

```javascript
const workbook = new ExcelJS.Workbook();
const sheet = workbook.addWorksheet('Sheet1');

sheet.addRow(['품목코드', '수량']);
sheet.addRow(['A001', 5]);

const data = await workbook.xlsx.writeBuffer();

saveAs(new Blob([data]), '품목.xlsx');
```

### writeBuffer

파일의 내용을 만들어 Promise 로 돌려준다. `await` 하거나 `then` 으로 받아야 한다. `await` 를 빼면 Blob 에 Promise 가 들어가서 열리지 않는 파일이 저장된다.

## 파일 읽기

### 파일 선택

`<input type="file">` 에서 사용자가 파일을 고르면 `onChange` 가 호출된다. 고른 파일은 `e.target.files` 에 들어 있다.

```jsx
onChangeFile = (e) => {
    const file = e.target.files[0];

    console.log(file.name);     // 파일 이름
    console.log(file.size);     // 바이트
};

render() {
    return <input type="file" onChange={this.onChangeFile} />;
}
```

### files

배열이 아니다. 인덱스와 `length` 는 쓸 수 있지만 `map` 은 없다. 사용자가 선택을 취소하면 길이가 0 이다.

```javascript
const files = [...e.target.files];  // 배열로 바꾼다
```

### 같은 파일 다시 선택

같은 파일을 다시 고르면 값이 바뀌지 않은 것이라 `onChange` 가 호출되지 않는다. 다시 고를 수 있게 하려면 처리한 뒤 입력 요소의 값을 비운다.

```javascript
e.target.value = '';
```

### 내용 읽기

File 의 내용을 읽는 것은 시간이 걸리는 작업이라 Promise 를 돌려준다.

| 메서드 | 돌려주는 값 |
| --- | --- |
| `file.text()` | 문자열로 끝나는 Promise |
| `file.arrayBuffer()` | 이진 데이터로 끝나는 Promise |

```javascript
const text = await file.text();
```

### FileReader

Promise 가 아니라 이벤트로 결과를 받는 예전 방식이다. 읽기가 끝나면 `onload` 에 넣은 함수가 호출된다.

```javascript
const reader = new FileReader();

reader.onload = () => {
    console.log(reader.result);     // 읽은 내용
};

reader.readAsText(file);            // 읽기를 시작만 하고 바로 다음 줄로 넘어간다
```

`readAsText` 다음 줄에서는 `reader.result` 가 아직 비어 있다.

## 서버로 파일 보내기

`FormData` 에 파일을 담아 요청의 본문으로 보낸다. JSON 으로는 파일을 그대로 보낼 수 없다.

```javascript
const formData = new FormData();
formData.append('file', file);
formData.append('docNo', 'D001');

await fetch('/api/upload', { method: 'POST', body: formData });
```

`FormData` 를 본문으로 줄 때는 `Content-Type` 헤더를 직접 지정하지 않는다. 브라우저가 알맞은 값을 넣는다.

---

## 정리

- 브라우저의 JS 는 사용자가 고른 파일만 읽을 수 있고, 저장은 다운로드로만 한다.
- Blob: 파일의 내용에 해당하는 데이터 덩어리. `new Blob([내용])` 으로 만든다.
- 저장: Blob 을 가리키는 임시 주소를 만들어 링크를 클릭한다. 라이브러리가 이 과정을 대신 한다.
- 엑셀 파일의 내용을 만드는 함수는 Promise 를 돌려준다.
- 사용자가 고른 파일은 `e.target.files` 에 있다. 배열이 아니다.
- 파일의 내용을 읽는 것은 Promise 또는 이벤트로 결과를 받는다.
- 파일을 서버로 보낼 때는 `FormData` 에 담는다.
