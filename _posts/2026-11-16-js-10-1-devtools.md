## 개발자 도구

개발자 도구는 브라우저에 들어 있는, 화면의 내부를 들여다보는 도구다. `F12` 로 연다.

### 탭

| 탭 | 보는 것 |
| --- | --- |
| Console | 출력, 에러, 경고. 코드를 직접 입력해 실행할 수 있다 |
| Sources | 소스 코드. 중단점을 걸어 실행을 멈춘다 |
| Network | 서버로 보낸 요청과 받은 응답 |
| Elements | 화면의 요소와 적용된 스타일 |
| Application | 저장소(`sessionStorage`, `localStorage`), 쿠키 |

---

## 에러 메시지

콘솔에 나오는 에러는 세 부분으로 되어 있다.

```
Uncaught TypeError: Cannot read properties of undefined (reading 'name')
    at Page.show (Page.js:42:27)
    at Page.onClick (Page.js:18:14)
    at HTMLButtonElement.callCallback (react-dom.development.js:188:14)
```

| 부분 | 예 | 뜻 |
| --- | --- | --- |
| 종류 | `TypeError` | 어떤 종류의 에러인가 |
| 메시지 | `Cannot read properties of undefined (reading 'name')` | 무엇이 잘못됐는가 |
| 호출 경로 | `at Page.show (Page.js:42:27)` | 어디서 났는가 |

### 호출 경로

맨 윗줄이 에러가 난 곳이고, 아래로 갈수록 그 함수를 호출한 쪽이다. 각 줄은 `함수 이름 (파일:줄:칸)` 이다. 위에서부터 읽다가 내 소스 파일이 처음 나오는 줄을 본다.

### 자주 보는 메시지

| 메시지 | 뜻 |
| --- | --- |
| `Cannot read properties of undefined (reading 'x')` | `undefined` 인 값에서 `.x` 를 읽었다. 문제는 `x` 가 아니라 그 앞의 값이다 |
| `Cannot read properties of null (reading 'x')` | `null` 인 값에서 `.x` 를 읽었다 |
| `x is not a function` | 함수가 아닌 것을 호출했다. 대개 `undefined` 다 |
| `x is not defined` | 그런 이름의 변수가 없다 |
| `Cannot access 'x' before initialization` | 선언한 줄보다 위에서 썼다 |
| `Assignment to constant variable` | `const` 변수에 다시 할당했다 |
| `Unexpected token` | 문법이 틀렸다. `JSON.parse` 에서 나면 JSON 형식이 아니다 |

### Uncaught (in promise)

`await` 하지 않았거나 `catch` 가 없는 Promise 가 실패했다는 뜻이다.

```
Uncaught (in promise) Error: 조회 실패
```

## Console

### 출력의 구분

| 표시 | 뜻 |
| --- | --- |
| 흰색 | `console.log` |
| 노란색 | 경고. 실행은 계속된다 |
| 빨간색 | 에러. 그 작업은 거기서 끝났다 |

### 객체의 출력

객체를 출력하면 펼쳐 보는 시점의 내용이 보인다. 출력한 뒤에 객체가 바뀌었으면 바뀐 내용이 보인다. 출력한 시점의 내용을 보려면 문자열로 바꿔 출력한다.

```javascript
console.log(JSON.stringify(row));
```

### 직접 실행

콘솔에 식을 입력하면 그 화면에서 실행된다. 중단점에서 멈춘 상태면 그 위치의 변수를 읽을 수 있다.

---

## Sources

### 중단점

소스의 줄 번호를 누르면 중단점이 걸린다. 실행이 그 줄에 도달하면 그 줄을 실행하기 전에 멈춘다. 멈춘 상태에서 변수의 값을 볼 수 있다.

### 실행 제어

| 버튼 | 하는 일 |
| --- | --- |
| Resume | 다음 중단점까지 계속 실행한다 |
| Step over | 지금 줄을 실행하고 다음 줄에서 멈춘다. 함수 호출은 안으로 들어가지 않는다 |
| Step into | 지금 줄에서 호출하는 함수 안으로 들어간다 |
| Step out | 지금 함수를 끝까지 실행하고 호출한 곳에서 멈춘다 |

### 멈춘 상태에서 보는 것

| 영역 | 내용 |
| --- | --- |
| Scope | 지금 위치에서 보이는 변수와 그 값. 지역, 클로저, 전역으로 나뉘어 있다 |
| Call Stack | 지금 함수가 호출된 경로 |
| Watch | 계속 지켜볼 식을 등록한다 |

### 조건부 중단점

줄 번호를 오른쪽 클릭해서 조건을 넣으면 그 조건이 참일 때만 멈춘다. 반복문 안에서 특정 값일 때만 보고 싶을 때 쓴다.

```javascript
row.itemCd === 'A001'
```

### debugger

코드에 `debugger;` 를 적으면 개발자 도구가 열려 있을 때 그 줄에서 멈춘다.

### 에러에서 멈추기

"Pause on exceptions" 를 켜면 에러가 던져지는 순간에 멈춘다. "Pause on caught exceptions" 까지 켜면 `try/catch` 로 잡힌 에러에서도 멈춘다. 빈 `catch` 가 삼킨 에러를 찾을 때 쓴다.

## Network

서버로 보낸 요청이 한 줄씩 나온다.

### 요청 한 줄에서 보는 것

| 항목 | 내용 |
| --- | --- |
| Status | 상태 코드 |
| Headers | 요청과 응답의 헤더. 요청 주소와 메서드 |
| Payload | 보낸 데이터 |
| Response | 받은 본문 |
| Timing | 걸린 시간 |

### 실패의 구분

| 표시 | 뜻 | 볼 곳 |
| --- | --- | --- |
| 400번대 | 요청이 잘못됐다 | Payload 에서 보낸 값, Response 의 메시지 |
| 500번대 | 서버에서 오류가 났다 | Response 의 메시지, 서버 로그 |
| `(failed)`, `CORS error` | 응답을 받지 못했거나 브라우저가 막았다 | Console 의 메시지 |
| `(pending)` | 아직 응답이 오지 않았다 | 서버 |
| 요청이 목록에 없다 | 요청을 보내는 코드가 실행되지 않았다 | 화면 코드 |

### 화면 문제와 서버 문제의 구분

| 확인 | 결과 | 원인이 있는 곳 |
| --- | --- | --- |
| 요청이 나갔는가 | 나가지 않았다 | 화면 코드 |
| 보낸 값이 맞는가 | 틀리다 | 화면 코드 |
| 응답의 값이 맞는가 | 틀리다 | 서버 |
| 응답의 값은 맞는데 화면이 틀리다 | | 화면 코드 |

### 옵션

| 옵션 | 하는 일 |
| --- | --- |
| Preserve log | 화면이 이동해도 목록을 지우지 않는다 |
| Disable cache | 저장해 둔 파일을 쓰지 않고 매번 새로 받는다 |

## React 개발자 도구

브라우저 확장 프로그램이다. 컴포넌트 트리를 보여 주고, 컴포넌트를 선택하면 그 컴포넌트의 props 와 state 의 현재 값을 볼 수 있다. 값을 직접 바꿔 볼 수도 있다.

화면이 기대와 다를 때 state 가 기대한 값인지를 먼저 확인한다. state 가 틀리면 state 를 바꾸는 코드의 문제이고, state 는 맞는데 화면이 틀리면 `render` 의 문제다.

## 정리

- 에러 메시지: 종류, 메시지, 호출 경로. 호출 경로의 맨 윗줄이 에러가 난 곳이다.
- `Cannot read properties of undefined (reading 'x')`: 문제는 `x` 앞의 값이 `undefined` 인 것이다.
- Console: 객체는 펼쳐 보는 시점의 내용이 보인다.
- Sources: 중단점으로 멈추고 Scope 에서 변수의 값을 본다.
- Network: 요청이 나갔는지, 보낸 값이 맞는지, 응답이 맞는지로 화면과 서버의 문제를 구분한다.
- React 개발자 도구: 컴포넌트의 props 와 state 를 본다.
