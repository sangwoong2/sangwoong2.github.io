## 클래스

클래스는 객체를 만드는 틀이다. `new 클래스()` 로 객체를 만들고, 그렇게 만든 객체를 인스턴스라고 한다.

```javascript
class Page {
    name = '화면';
}

const page = new Page();

console.log(page.name);     // '화면'
```

### new

`new` 없이 호출하면 에러가 난다.

```javascript
Page();     // TypeError: Class constructor Page cannot be invoked without 'new'
```

### 선언 전 사용

선언한 줄보다 위에서 쓸 수 없다.

```javascript
const page = new Page();    // ReferenceError: Cannot access 'Page' before initialization
class Page {}
```

---

## 클래스의 구성

| 구성 | 모양 | 저장되는 곳 | 실행되는 때 |
| --- | --- | --- | --- |
| 필드 | `name = 값;` | 인스턴스마다 | 인스턴스를 만들 때 |
| 생성자 | `constructor() { }` | 클래스에 하나 | 인스턴스를 만들 때 |
| 메서드 | `show() { }` | 클래스에 하나 | 호출할 때 |
| getter | `get util() { }` | 클래스에 하나 | 속성을 읽을 때 |
| static | `static make() { }` | 클래스 자체 | 클래스 이름으로 호출할 때 |

## 필드

필드는 인스턴스가 갖는 변수다.

### 실행 시점

인스턴스를 만들 때마다 위에서 아래로 실행된다. 생성자의 본문보다 먼저 실행된다.

```javascript
const order = [];

class Page {
    a = order.push('필드');

    constructor() {
        order.push('생성자');
    }
}

new Page();

console.log(order);     // ['필드', '생성자']
```

### 순서

필드의 초기값에서 `this` 로 다른 필드를 쓸 수 있다. 위에 있는 필드만 값이 들어 있고, 아래에 있는 필드는 아직 `undefined` 다.

```javascript
class Page {
    b = this.a;     // 아직 a 가 만들어지지 않았다
    a = 1;
}

console.log(new Page().b);  // undefined
```

메서드는 필드보다 먼저 준비되어 있으므로 필드의 초기값에서 호출할 수 있다. 필드에 담은 화살표 함수는 그 필드가 실행된 뒤에야 호출할 수 있다.

```javascript
class Page {
    grid = this.initGrid();     // 가능: initGrid 는 메서드다

    initGrid() {
        return 'grid';
    }
}
```

```javascript
class Page {
    grid = this.initGrid();     // TypeError: this.initGrid is not a function

    initGrid = () => 'grid';
}
```

### 인스턴스마다 따로

인스턴스를 만들 때마다 초기값이 새로 만들어진다. 인스턴스끼리 공유하지 않는다.

```javascript
class Page {
    rows = [];
}

const a = new Page();
const b = new Page();
a.rows.push(1);

console.log(a.rows);    // [1]
console.log(b.rows);    // []
```

## 생성자

`constructor` 는 인스턴스를 만들 때 실행되는 메서드다. `new` 에 넘긴 인자를 받는다.

```javascript
class Page {
    constructor(name) {
        this.name = name;
    }
}

console.log(new Page('화면').name);     // '화면'
```

## 상속

`class 자식 extends 부모` 로 쓴다. 자식 클래스의 인스턴스는 부모 클래스의 필드와 메서드를 함께 갖는다.

### 메서드 재정의

자식에 같은 이름의 메서드를 만들면 자식의 것이 호출된다. 부모의 메서드는 `super.메서드()` 로 호출한다.

```javascript
class Base {
    hello() {
        return 'Base';
    }
}

class Page extends Base {
    hello() {
        return super.hello() + ' → Page';
    }
}

console.log(new Page().hello());    // 'Base → Page'
```

### 생성자와 super

자식 클래스의 생성자에서는 `this` 를 쓰기 전에 `super()` 를 호출해야 한다. `super()` 는 부모의 생성자를 실행한다.

```javascript
class Page extends Base {
    constructor() {
        this.name = '화면';     // ReferenceError: Must call super constructor in derived class before accessing 'this' or returning from derived constructor
    }
}
```

```javascript
class Page extends Base {
    constructor(props) {
        super(props);
        this.name = '화면';
    }
}
```

자식 클래스에 생성자를 적지 않으면 받은 인자를 그대로 부모의 생성자에 넘긴다.

### 실행 순서

부모의 필드, 부모의 생성자, 자식의 필드, 자식의 생성자 순서다.

```javascript
const order = [];

class Base {
    a = order.push('부모 필드');
    constructor() { order.push('부모 생성자'); }
}

class Page extends Base {
    b = order.push('자식 필드');
    constructor() { super(); order.push('자식 생성자'); }
}

new Page();

console.log(order);     // ['부모 필드', '부모 생성자', '자식 필드', '자식 생성자']
```

### 필드와 메서드의 이름이 같을 때

필드가 이긴다. 필드는 인스턴스에, 메서드는 클래스에 저장되고, 속성을 찾을 때 인스턴스를 먼저 보기 때문이다. 부모가 필드에 담은 화살표 함수는 자식이 같은 이름의 메서드를 만들어도 재정의되지 않는다.

```javascript
class Base {
    save = () => '부모 필드';
}

class Page extends Base {
    save() {
        return '자식 메서드';
    }
}

console.log(new Page().save());     // '부모 필드'
```

## static

`static` 을 붙인 필드와 메서드는 인스턴스가 아니라 클래스 자체에 속한다. 클래스 이름으로 접근한다. 인스턴스에서는 접근할 수 없다.

```javascript
class Page {
    static VERSION = '1.0';
}

console.log(Page.VERSION);          // '1.0'
console.log(new Page().VERSION);    // undefined
```

## 비공개

### #

이름 앞에 `#` 을 붙인 필드는 클래스 안에서만 접근할 수 있다.

```javascript
class Page {
    #secret = 1;

    get() {
        return this.#secret;
    }
}

const page = new Page();

console.log(page.get());        // 1
console.log(page.secret);       // undefined
console.log(Object.keys(page)); // []
```

### _

이름 앞의 `_` 는 "내부에서만 쓴다"는 약속이다. 문법으로 막히지 않는다.

```javascript
class Page {
    _secret = 1;
}

console.log(new Page()._secret);    // 1
```

## instanceof

`객체 instanceof 클래스` 는 객체가 그 클래스 또는 그 클래스를 상속한 클래스로 만들어졌으면 `true` 다.

```javascript
const page = new Page();

console.log(page instanceof Page);  // true
console.log(page instanceof Base);  // true
console.log({} instanceof Page);    // false
```

---

## 정리

- 클래스: 객체를 만드는 틀. `new` 로 인스턴스를 만든다.
- 필드: 인스턴스마다 갖는 변수. 인스턴스를 만들 때 위에서 아래로 실행되고, 생성자의 본문보다 먼저 실행된다.
- 필드의 초기값에서 아래에 있는 필드는 아직 `undefined` 다. 메서드는 호출할 수 있다.
- 상속: 자식 생성자에서는 `this` 전에 `super()` 를 호출한다. 부모의 메서드는 `super.메서드()` 로 호출한다.
- 필드와 메서드의 이름이 같으면 필드가 이긴다.
- `static`: 클래스 자체에 속한다. 인스턴스에서는 접근할 수 없다.
- `#` 은 문법으로 막는 비공개, `_` 는 약속이다.
