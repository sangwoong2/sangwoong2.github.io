## 배열

배열은 값을 순서대로 담은 객체다.

### 범위 밖 인덱스

에러가 아니라 `undefined` 다.

```javascript
const rows = [1, 2];

console.log(rows[5]);   // undefined
```

### 빈 배열

참 같은 값이다. 비어 있는지는 `length` 로 확인한다.

```javascript
const rows = [];

console.log(rows ? '참' : '거짓');  // '참'
console.log(rows.length === 0);     // true
```

## 배열 메서드

| 메서드 | 하는 일 | 돌려주는 값 | 원본 변경 |
| --- | --- | --- | --- |
| `map(함수)` | 요소마다 함수의 결과로 바꾼다 | 새 배열 | 없음 |
| `filter(함수)` | 함수의 결과가 참 같은 요소만 남긴다 | 새 배열 | 없음 |
| `find(함수)` | 함수의 결과가 참 같은 첫 요소를 찾는다 | 요소. 없으면 `undefined` | 없음 |
| `findIndex(함수)` | 위와 같은 요소의 위치를 찾는다 | 위치. 없으면 `-1` | 없음 |
| `some(함수)` | 하나라도 참 같은지 확인한다 | 불리언 | 없음 |
| `every(함수)` | 모두 참 같은지 확인한다 | 불리언 | 없음 |
| `reduce(함수, 초기값)` | 요소를 차례로 누적한다 | 누적한 값 | 없음 |
| `includes(값)` | 값이 들어 있는지 확인한다 | 불리언 | 없음 |
| `indexOf(값)` | 값의 위치를 찾는다 | 위치. 없으면 `-1` | 없음 |
| `concat(배열)` | 뒤에 이어 붙인다 | 새 배열 | 없음 |
| `slice(시작, 끝)` | 일부를 잘라 낸다 | 새 배열 | 없음 |
| `join(구분자)` | 요소를 이어 붙인다 | 문자열 | 없음 |
| `forEach(함수)` | 요소마다 함수를 실행한다 | `undefined` | 없음 |
| `push(값)` | 뒤에 추가한다 | 바뀐 길이 | **있음** |
| `pop()` | 마지막 요소를 꺼낸다 | 꺼낸 요소 | **있음** |
| `shift()` | 첫 요소를 꺼낸다 | 꺼낸 요소 | **있음** |
| `unshift(값)` | 앞에 추가한다 | 바뀐 길이 | **있음** |
| `splice(시작, 개수, 넣을 값)` | 일부를 지우고 그 자리에 넣는다 | 지운 요소의 배열 | **있음** |
| `sort(비교 함수)` | 정렬한다 | 원본 배열 | **있음** |
| `reverse()` | 순서를 뒤집는다 | 원본 배열 | **있음** |

함수를 받는 메서드는 그 함수를 `(요소, 인덱스, 배열)` 로 호출한다.

## 콜백의 반환값

`map`, `filter`, `find`, `some`, `every` 는 넘겨받은 함수가 돌려주는 값을 쓴다. 함수가 값을 돌려주지 않으면 `undefined` 를 돌려준 것으로 처리된다.

### map

`{ }` 를 쓰고 `return` 을 빠뜨리면 `undefined` 가 든 배열이 나온다.

```javascript
console.log([1, 2, 3].map((n) => n * 2));       // [2, 4, 6]
console.log([1, 2, 3].map((n) => { n * 2; }));  // [undefined, undefined, undefined]
```

객체를 돌려줄 때는 `( )` 로 감싼다. 감싸지 않으면 `{ }` 가 함수의 본문으로 읽힌다.

```javascript
console.log([1, 2].map((n) => ({ value: n })));     // [{ value: 1 }, { value: 2 }]
```

### filter

`return` 을 빠뜨리면 모든 요소가 걸러져 빈 배열이 나온다.

```javascript
console.log([1, 2, 3].filter((n) => { n > 1; }));   // []
```

### forEach

함수가 돌려주는 값을 쓰지 않는다. `forEach` 의 결과는 항상 `undefined` 다.

```javascript
const result = [1, 2, 3].forEach((n) => n * 2);

console.log(result);    // undefined
```

## 못 찾았을 때

| 메서드 | 결과 |
| --- | --- |
| `find` | `undefined` |
| `findIndex`, `indexOf` | `-1` |
| `filter` | `[]` |
| `includes`, `some` | `false` |

`find` 의 결과를 확인하지 않고 속성을 읽으면 에러가 난다.

```javascript
const rows = [{ id: 1 }];

console.log(rows.find((r) => r.id === 9));      // undefined
console.log(rows.find((r) => r.id === 9).id);   // TypeError: Cannot read properties of undefined (reading 'id')
```

## 객체가 든 배열

### includes, indexOf

`===` 로 비교한다. 객체는 참조를 비교하므로 내용이 같은 객체를 새로 만들어 찾으면 찾지 못한다. 내용으로 찾으려면 `find`, `some` 을 쓴다.

```javascript
const rows = [{ id: 1 }];

console.log(rows.includes({ id: 1 }));          // false
console.log(rows.some((r) => r.id === 1));      // true
```

### find, filter 가 돌려주는 객체

복사본이 아니라 원본 배열에 들어 있는 그 객체다. 내용을 바꾸면 원본 배열에서도 바뀐다.

```javascript
const rows = [{ id: 1 }, { id: 2 }];
const found = rows.find((r) => r.id === 2);

found.id = 9;

console.log(rows);  // [{ id: 1 }, { id: 9 }]
```

| 식 | 결과 |
| --- | --- |
| `[].some(함수)` | `false` |
| `[].every(함수)` | `true` |
| `[].reduce(함수, 0)` | `0` |
| `[].reduce(함수)` | TypeError: Reduce of empty array with no initial value |

## reduce 의 초기값

초기값을 생략하면 첫 요소가 누적값의 시작이 된다. 객체가 든 배열에서 초기값을 빠뜨리면 첫 객체가 누적값이 되어 계산이 틀린다.

```javascript
const rows = [{ qty: 1 }, { qty: 2 }];

console.log(rows.reduce((sum, r) => sum + r.qty, 0));   // 3
console.log(rows.reduce((sum, r) => sum + r.qty));      // '[object Object]2'
```

## sort

### 원본 변경

원본 배열을 정렬하고 그 배열을 돌려준다. 원본을 남기려면 복사한 뒤 정렬한다.

```javascript
const a = [3, 1, 2];
const b = [...a].sort();

console.log(a);     // [3, 1, 2]
console.log(b);     // [1, 2, 3]
```

### 기본 정렬

비교 함수를 주지 않으면 요소를 문자열로 바꿔 글자 순서로 정렬한다. 숫자도 문자열로 비교된다.

```javascript
console.log([10, 9, 1, 100].sort());    // [1, 10, 100, 9]
```

### 비교 함수

`(a, b)` 를 받아 숫자를 돌려준다. 음수면 `a` 가 앞, 양수면 `b` 가 앞이다.

```javascript
console.log([10, 9, 1, 100].sort((a, b) => a - b));     // [1, 9, 10, 100]
console.log([10, 9, 1, 100].sort((a, b) => b - a));     // [100, 10, 9, 1]
```

불리언을 돌려주면 정렬되지 않는다. `true` 는 `1`, `false` 는 `0` 으로 처리되어 음수가 나오지 않기 때문이다.

```javascript
const rows = [{ code: 'b' }, { code: 'a' }];

console.log(rows.sort((x, y) => x.code > y.code));              // [{ code: 'b' }, { code: 'a' }]
console.log(rows.sort((x, y) => x.code.localeCompare(y.code))); // [{ code: 'a' }, { code: 'b' }]
```

## push 의 반환값

배열이 아니라 바뀐 길이를 돌려준다.

```javascript
const a = [1, 2];
const b = a.push(3);

console.log(a);     // [1, 2, 3]
console.log(b);     // 3
```

## slice, splice 의 차이

| | `slice(시작, 끝)` | `splice(시작, 개수)` |
| --- | --- | --- |
| 원본 변경 | 없음 | 있음 |
| 두 번째 인자 | 끝 위치 | 지울 개수 |
| 돌려주는 값 | 잘라 낸 새 배열 | 지운 요소의 배열 |

```javascript
const a = [1, 2, 3, 4];

console.log(a.slice(1, 3));     // [2, 3]
console.log(a);                 // [1, 2, 3, 4]

console.log(a.splice(1, 2));    // [2, 3]
console.log(a);                 // [1, 4]
```

## 반복문

| 방법 | 반복마다 받는 것 | `break` |
| --- | --- | --- |
| `for (let i = 0; i < 배열.length; i++)` | 인덱스(숫자) | 가능 |
| `for (const 값 of 배열)` | 요소 | 가능 |
| `for (const 키 in 배열)` | 인덱스(**문자열**) | 가능 |
| `배열.forEach(함수)` | 요소, 인덱스 | 불가 |

### for...in

인덱스를 문자열로 준다. 숫자처럼 더하면 문자열 연결이 된다.

```javascript
for (const i in ['a', 'b']) {
    console.log(i + 1);     // '01', '11'
}
```

### forEach

중간에 멈출 수 없다. 함수 안의 `return` 은 그 요소의 처리만 끝내고 다음 요소로 넘어간다.

```javascript
const result = [];

[1, 2, 3].forEach((n) => {
    if (n === 2) return;
    result.push(n);
});

console.log(result);    // [1, 3]
```

## 정리

- 배열: 범위 밖 인덱스는 `undefined` 다. 빈 배열은 참 같은 값이다.
- 원본을 바꾸는 메서드: `push`, `pop`, `shift`, `unshift`, `splice`, `sort`, `reverse`.
- `map`, `filter`: 콜백에서 `return` 을 빠뜨리면 `undefined` 배열, 빈 배열이 나온다.
- `find`: 못 찾으면 `undefined` 다. 돌려준 객체는 원본 배열의 그 객체다.
- `includes`, `indexOf`: 객체는 참조로 비교한다.
- `reduce`: 초기값을 주지 않으면 첫 요소가 누적값의 시작이 된다.
- `sort`: 원본을 바꾼다. 비교 함수가 없으면 문자열 순서로 정렬한다.
- `push`: 바뀐 길이를 돌려준다.
- `for...in`: 인덱스를 문자열로 준다. `forEach` 는 중간에 멈출 수 없다.
