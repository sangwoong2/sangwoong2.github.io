## 실행 환경

JS 언어 자체에는 화면, 주소, 저장소, 타이머를 다루는 기능이 없다. 이것들은 JS 를 실행하는 환경이 제공한다. 브라우저에서 실행되는 JS 는 브라우저가 제공하는 객체를 쓴다.

| 제공하는 쪽 | 예 |
| --- | --- |
| JS 언어 | `Array`, `Object`, `Promise`, `JSON`, `Math` |
| 브라우저 | `window`, `document`, `location`, `sessionStorage`, `setTimeout`, `fetch`, `console` |

---

## window

`window` 는 브라우저 창을 나타내는 객체이고, 브라우저에서 가장 바깥에 있는 전역 객체다. 브라우저가 제공하는 것들은 `window` 의 속성이다.

### 생략

`window.` 는 생략할 수 있다. 아래 두 줄은 같다.

```javascript
window.setTimeout(callback, 1000);
setTimeout(callback, 1000);
```

---

## document

`document` 는 화면에 그려진 문서를 나타내는 객체다. 화면의 요소를 찾고 바꾸는 데 쓴다.

### 요소 찾기

| 메서드 | 돌려주는 값 | 없을 때 |
| --- | --- | --- |
| `getElementById('id')` | 요소 하나 | `null` |
| `querySelector('선택자')` | 처음 찾은 요소 하나 | `null` |
| `querySelectorAll('선택자')` | 찾은 요소 전부 | 길이가 0 인 목록 |

못 찾으면 `null` 이 나오므로, 결과의 속성을 바로 읽으면 에러가 난다.

```javascript
const el = document.getElementById('none');

console.log(el);        // null
el.value;               // TypeError: Cannot read properties of null (reading 'value')
```

### querySelectorAll 의 결과

배열이 아니다. `forEach` 는 있지만 `map`, `filter` 는 없다. 배열 메서드를 쓰려면 배열로 바꾼다.

```javascript
const list = document.querySelectorAll('div');

console.log(Array.isArray(list));   // false
console.log(typeof list.forEach);   // 'function'
console.log(typeof list.map);       // 'undefined'

const array = [...list];            // 배열로 바꾼다
```

### React 와 document

React 는 state 를 바탕으로 화면을 그린다. `document` 로 요소를 직접 바꾸면 React 가 알고 있는 화면과 실제 화면이 달라지고, 다시 그려질 때 바꾼 내용이 사라질 수 있다. 요소가 필요하면 8-5 "ref"를 쓴다.

## location

`location` 은 현재 주소를 나타내는 객체다.

주소가 `https://example.test/menu/BL?divCd=1000&ym=202611#top` 일 때의 값이다.

| 속성 | 값 |
| --- | --- |
| `location.href` | 주소 전체 |
| `location.origin` | `'https://example.test'` |
| `location.pathname` | `'/menu/BL'` |
| `location.search` | `'?divCd=1000&ym=202611'` |
| `location.hash` | `'#top'` |

### 쿼리 문자열

`URLSearchParams` 로 값을 꺼낸다. 값은 항상 문자열이고, 없는 이름은 `null` 이다.

```javascript
const params = new URLSearchParams(location.search);

console.log(params.get('divCd'));   // '1000'
console.log(params.get('none'));    // null
```

### 주소에 넣는 값

한글이나 `&`, `=`, 공백 같은 글자는 `encodeURIComponent` 로 바꿔서 넣는다.

```javascript
console.log(encodeURIComponent('품목 A&B'));    // '%ED%92%88%EB%AA%A9%20A%26B'
```

## 저장소

브라우저에 문자열을 저장해 두는 객체다.

### 종류

| | `sessionStorage` | `localStorage` |
| --- | --- | --- |
| 유지되는 기간 | 그 탭을 닫을 때까지 | 지울 때까지 |
| 공유 범위 | 그 탭 | 같은 사이트의 모든 탭 |

둘은 서로 다른 저장소다. 한쪽에 넣은 값은 다른 쪽에서 읽을 수 없다.

### 메서드

| 메서드 | 하는 일 | 돌려주는 값 |
| --- | --- | --- |
| `setItem(키, 값)` | 저장한다 | 없음 |
| `getItem(키)` | 읽는다 | 문자열. 없으면 `null` |
| `removeItem(키)` | 지운다 | 없음 |
| `clear()` | 전부 지운다 | 없음 |

### 저장되는 타입

문자열만 저장된다. 다른 타입을 넣으면 문자열로 변환되어 저장된다.

```javascript
sessionStorage.setItem('count', 5);
sessionStorage.setItem('flag', false);
sessionStorage.setItem('user', { name: '홍길동' });

console.log(sessionStorage.getItem('count'));   // '5'  (숫자가 아니다)
console.log(sessionStorage.getItem('flag'));    // 'false'  (참 같은 값이다)
console.log(sessionStorage.getItem('user'));    // '[object Object]'
```

### 객체 저장

JSON 문자열로 바꿔서 넣고, 읽을 때 다시 객체로 바꾼다.

```javascript
sessionStorage.setItem('user', JSON.stringify({ name: '홍길동' }));

const user = JSON.parse(sessionStorage.getItem('user'));

console.log(user.name);     // '홍길동'
```

### 없는 키

`getItem` 은 `null` 을 돌려준다. `JSON.parse(null)` 은 에러 없이 `null` 이 나온다. 속성을 읽기 전에 기본값을 준다.

```javascript
const saved = JSON.parse(sessionStorage.getItem('none'));

console.log(saved);         // null
console.log(saved || {});   // {}
```

## console

개발자 도구의 콘솔에 출력하는 객체다.

| 메서드 | 출력 |
| --- | --- |
| `console.log(값)` | 일반 출력 |
| `console.warn(값)` | 경고. 노란색으로 표시된다 |
| `console.error(값)` | 에러. 빨간색으로 표시되고 호출 경로가 붙는다 |
| `console.table(배열)` | 표로 출력 |

### 객체를 출력할 때

`console.log` 에 객체를 넘기면 값의 복사본이 아니라 그 객체에 대한 참조가 출력된다. 콘솔에서 펼쳐 보는 시점의 내용이 보인다. 출력한 뒤에 객체가 바뀌었으면 바뀐 내용이 보인다.

```javascript
const row = { qty: 1 };

console.log(row);                   // 펼쳐 보면 qty: 2 로 보일 수 있다
console.log(JSON.stringify(row));   // '{"qty":1}'  (출력한 시점의 내용)

row.qty = 2;
```

## 정리

- `window`, `document`, `location`, 저장소, 타이머, `console` 은 JS 언어가 아니라 브라우저가 제공한다.
- `getElementById`, `querySelector`: 못 찾으면 `null` 이다.
- `querySelectorAll`: 배열이 아니다. `map` 을 쓰려면 배열로 바꾼다.
- `location.search`: 쿼리 문자열. `URLSearchParams` 로 값을 꺼낸다. 값은 문자열이다.
- 저장소: 문자열만 저장된다. 객체는 `JSON.stringify` 로 넣고 `JSON.parse` 로 꺼낸다.
- `console.log(객체)`: 펼쳐 보는 시점의 내용이 보인다.
