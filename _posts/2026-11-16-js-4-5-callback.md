## 콜백

콜백은 다른 함수에 넘겨서 그 함수가 호출하게 한 함수다. 함수의 종류가 아니라 함수를 쓰는 방식에 붙은 이름이다.

```javascript
const calculate = (a, b, callback) => {
    const result = a + b;
    return callback(result);
};

console.log(calculate(1, 2, (v) => v * 10));    // 30
```

`calculate` 는 더하는 일만 알고, 더한 뒤에 무엇을 할지는 넘겨받은 함수에 맡긴다.

### 넘기기와 호출하기

함수 이름만 적으면 함수 자체고, `( )` 를 붙이면 호출한 결과다.

```javascript
const hello = () => 'hi';

console.log(typeof hello);      // 'function'
console.log(typeof hello());    // 'string'
```

콜백 자리에 `( )` 를 붙여 넘기면 그 자리에서 실행되고 결과가 넘어간다.

```javascript
button.onClick = save;      // 클릭하면 save 가 호출된다
button.onClick = save();    // 지금 save 를 호출하고 그 결과를 넣는다
```

### 호출하는 쪽

콜백을 언제, 몇 번, 어떤 인자로 호출할지는 넘겨받은 함수가 정한다. 호출하는 코드는 내 코드에 없다.

```javascript
const result = [];

['a', 'b'].forEach((value, index, array) => {
    result.push(value + index + array.length);
});

console.log(result);    // ['a02', 'b12']
```

`value`, `index`, `array` 는 내가 넣은 값이 아니라 `forEach` 가 넣어 준 값이다.

### 인자의 개수

받는 쪽이 넣어 주는 인자와 넘긴 함수가 받는 인자가 맞지 않으면 다른 결과가 나온다. `map` 은 콜백을 `(요소, 인덱스, 배열)` 로 호출하고, `parseInt` 는 두 번째 인자를 진법으로 쓴다.

```javascript
console.log(['1', '2', '3'].map(parseInt));                 // [1, NaN, NaN]
console.log(['1', '2', '3'].map((v) => parseInt(v)));       // [1, 2, 3]
```

## 고차함수

고차함수는 함수를 인자로 받거나 함수를 돌려주는 함수다.

### 함수를 받는 함수

공통된 부분은 고차함수가 갖고, 달라지는 부분만 함수로 받는다. `map`, `filter`, `forEach` 가 여기에 해당한다.

```javascript
const repeat = (times, fn) => {
    for (let i = 0; i < times; i++) {
        fn(i);
    }
};

repeat(3, (i) => console.log(i));   // 0, 1, 2
```

### 함수를 돌려주는 함수

설정을 받아 그에 맞는 함수를 만들어 준다.

```javascript
const between = (min, max) => (value) => value >= min && value <= max;
const isMonth = between(1, 12);

console.log(isMonth(5));    // true
console.log(isMonth(13));   // false
```

## 콜백 안의 return

콜백 안의 `return` 은 그 콜백만 끝낸다. 콜백을 넘긴 바깥 함수는 끝나지 않는다.

```javascript
const find = (rows) => {
    rows.forEach((row) => {
        if (row === 2) return 'found';  // 이 콜백만 끝난다
    });
    return 'none';
};

console.log(find([1, 2, 3]));   // 'none'
```

반복문 안의 `return` 은 그 함수를 끝낸다.

```javascript
const find = (rows) => {
    for (const row of rows) {
        if (row === 2) return 'found';
    }
    return 'none';
};

console.log(find([1, 2, 3]));   // 'found'
```

## 호출되는 시점

콜백은 넘긴 즉시 호출될 수도 있고 나중에 호출될 수도 있다. 넘겨받는 함수가 정한다.

| | 호출되는 시점 | 예 |
| --- | --- | --- |
| 동기 콜백 | 넘겨받은 함수가 실행되는 동안 | `map`, `filter`, `forEach`, `sort` |
| 비동기 콜백 | 넘겨받은 함수가 끝난 뒤 | `setTimeout`, 이벤트, 서버 응답 |

### 동기 콜백

다음 줄로 넘어가기 전에 콜백이 모두 호출된다.

```javascript
const order = [];

order.push(1);
[0].forEach(() => order.push(2));
order.push(3);

console.log(order);     // [1, 2, 3]
```

### 비동기 콜백

콜백을 맡기기만 하고 다음 줄로 넘어간다. 콜백은 지금 실행 중인 코드가 모두 끝난 뒤에 호출된다.

```javascript
const order = [];

order.push('A');
setTimeout(() => {
    order.push('C');
    console.log(order);     // ['A', 'B', 'C']
}, 0);
order.push('B');
```

7부 "비동기"에서 다룬다.

## 없을 수 있는 콜백

콜백을 넘기지 않으면 매개변수가 `undefined` 다. 그대로 호출하면 에러가 난다. `?.()` 로 호출하면 있을 때만 호출한다.

```javascript
const run = (callback) => callback();
run();      // TypeError: callback is not a function
```

```javascript
const run = (callback) => callback?.();

console.log(run());             // undefined
console.log(run(() => 1));      // 1
```

## 정리

- 콜백: 다른 함수에 넘겨서 그 함수가 호출하게 한 함수.
- 함수 이름만 적으면 함수를 넘기는 것이고, `( )` 를 붙이면 호출한 결과를 넘기는 것이다.
- 언제, 몇 번, 어떤 인자로 호출할지는 넘겨받은 함수가 정한다.
- 고차함수: 함수를 받거나 돌려주는 함수.
- 콜백 안의 `return` 은 그 콜백만 끝낸다.
- 동기 콜백은 넘겨받은 함수가 실행되는 동안, 비동기 콜백은 그 함수가 끝난 뒤에 호출된다.
