## Date

날짜와 시각을 나타내는 객체다. 안에는 1970년 1월 1일 0시(UTC)부터 지난 밀리초 숫자 하나가 들어 있다.

### 월

0 부터 센다. 1월이 `0`, 12월이 `11` 이다. 만들 때와 읽을 때 모두 해당한다.

```javascript
const d = new Date(2026, 10, 16);   // 2026년 11월 16일

console.log(d.getMonth());          // 10
console.log(d.getMonth() + 1);      // 11
```

### 문자열 해석

`new Date(문자열)` 은 형식에 따라 기준 시간대가 다르다.

| 문자열 | 결과 (한국 시간 기준) |
| --- | --- |
| `'2026-11-16'` | 11월 16일 **9시**. UTC 0시로 해석한다 |
| `'2026-11-16T00:00:00'` | 11월 16일 0시. 현지 시간으로 해석한다 |
| `'2026/11/16'` | 11월 16일 0시. 현지 시간으로 해석한다 |
| `'20261116'` | Invalid Date |

```javascript
console.log(new Date('2026-11-16').getHours());             // 9
console.log(new Date('2026-11-16T00:00:00').getHours());    // 0
```

### Invalid Date

해석할 수 없는 문자열로 만든 Date 객체다. 에러가 나지 않는다. `isNaN` 으로 확인한다.

```javascript
const d = new Date('20261116');

console.log(isNaN(d));      // true
```

### 범위를 넘는 값

없는 날짜를 주면 다음 달로 넘어간다. 에러가 나지 않는다.

```javascript
const d = new Date(2026, 10, 31);   // 11월 31일은 없다

console.log(d.getMonth() + 1, d.getDate());     // 12 1
```

## Date 메서드

| 메서드 | 하는 일 | 돌려주는 값 | 원본 변경 |
| --- | --- | --- | --- |
| `getFullYear()` | 연도를 읽는다 | 숫자 | 없음 |
| `getMonth()` | 월을 읽는다 | 0 ~ 11 | 없음 |
| `getDate()` | 일을 읽는다 | 1 ~ 31 | 없음 |
| `getDay()` | 요일을 읽는다 | 0(일요일) ~ 6(토요일) | 없음 |
| `getTime()` | 밀리초 숫자를 읽는다 | 숫자 | 없음 |
| `setMonth(월)`, `setDate(일)` | 월, 일을 바꾼다 | 밀리초 숫자 | **있음** |
| `toISOString()` | UTC 기준 문자열로 만든다 | 문자열 | 없음 |

이름이 비슷한 `getDate` 는 일이고 `getDay` 는 요일이다.

## Date 의 원본 변경

Date 는 객체다. `set` 으로 시작하는 메서드는 새 객체를 만들지 않고 그 객체의 내용을 바꾼다.

### 할당

할당하면 같은 객체를 가리킨다. 한쪽을 바꾸면 다른 쪽도 바뀐다. 복사하려면 `new Date(Date 객체)` 로 새로 만든다.

```javascript
const a = new Date(2026, 10, 16);
const b = a;
const c = new Date(a);

b.setDate(1);

console.log(a.getDate());   // 1
console.log(c.getDate());   // 16
```

### 월 더하기

그 달에 없는 날짜가 되면 다음 달로 넘어간다.

```javascript
const d = new Date(2026, 0, 31);    // 1월 31일
d.setMonth(d.getMonth() + 1);       // 2월 31일은 없다

console.log(d.getMonth() + 1, d.getDate());     // 3 3
```

## Date 비교

### 대소 비교

`<`, `>` 는 Date 객체를 밀리초 숫자로 바꿔서 비교한다.

```javascript
console.log(new Date(2026, 10, 16) < new Date(2026, 10, 17));   // true
```

### 일치 비교

`===` 는 참조를 비교한다. 같은 시각이어도 따로 만든 객체면 `false` 다. 시각이 같은지는 `getTime()` 으로 비교한다.

```javascript
const a = new Date(2026, 10, 16);
const b = new Date(2026, 10, 16);

console.log(a === b);                       // false
console.log(a.getTime() === b.getTime());   // true
```

### 빼기

Date 객체끼리 빼면 밀리초 차이가 나온다.

```javascript
const from = new Date(2026, 10, 16);
const to = new Date(2026, 10, 30);

console.log(to - from);                             // 1209600000
console.log((to - from) / (1000 * 60 * 60 * 24));   // 14
```

## toISOString

UTC 기준 문자열을 돌려준다. 한국 시간과 9시간 차이가 나므로 날짜가 하루 앞으로 나올 수 있다. `JSON.stringify` 도 Date 객체를 이 형식으로 바꾼다.

```javascript
const d = new Date(2026, 10, 16);   // 한국 시간 11월 16일 0시

console.log(d.toISOString());           // '2026-11-15T15:00:00.000Z'
console.log(JSON.stringify({ d }));     // '{"d":"2026-11-15T15:00:00.000Z"}'
```

## 날짜 문자열

날짜를 `'20261116'` 같은 문자열로 다루는 것이다.

### 비교

자릿수와 형식이 같으면 문자열 대소 비교의 결과가 날짜 순서와 같다.

```javascript
const ymd = '20261116';

console.log(ymd >= '20261101' && ymd <= '20261130');    // true
```

형식이 다르면 결과가 맞지 않는다.

```javascript
console.log('20261116' < '2026-12-01');     // false
```

## moment

날짜를 다루는 라이브러리다. `moment(값)` 은 moment 객체를 만든다. 문자열, Date 객체를 넘길 수 있고 인자가 없으면 현재 시각이다.

### moment 메서드

| 메서드 | 하는 일 | 돌려주는 값 | 원본 변경 |
| --- | --- | --- | --- |
| `format(형식)` | 형식에 맞춘 문자열을 만든다 | 문자열 | 없음 |
| `isValid()` | 해석할 수 있는 날짜인지 확인한다 | 불리언 | 없음 |
| `add(숫자, 단위)` | 더한다 | 자기 자신 | **있음** |
| `subtract(숫자, 단위)` | 뺀다 | 자기 자신 | **있음** |
| `diff(다른 moment, 단위)` | 차이를 구한다 | 숫자 | 없음 |
| `clone()` | 복사한다 | 새 moment 객체 | 없음 |

### format 의 기호

대문자와 소문자가 다른 뜻이다. `MM` 은 월, `mm` 은 분이다.

| 기호 | 뜻 |
| --- | --- |
| `YYYY` | 연도 네 자리 |
| `MM` | 월 두 자리 |
| `DD` | 일 두 자리 |
| `HH` | 시 두 자리 (0 ~ 23) |
| `mm` | 분 두 자리 |
| `ss` | 초 두 자리 |

```javascript
const m = moment('20261116');

console.log(m.format('YYYYMMDD'));      // '20261116'
console.log(m.format('YYYY-MM-DD'));    // '2026-11-16'
console.log(m.format('YYYYMM'));        // '202611'
```

### 해석할 수 없는 값

에러가 나지 않는다. `format` 은 `'Invalid date'` 라는 문자열을 돌려준다.

```javascript
const m = moment('20261131');   // 11월 31일은 없다

console.log(m.isValid());               // false
console.log(m.format('YYYYMMDD'));      // 'Invalid date'
```

### add, subtract 의 원본 변경

moment 객체 자신을 바꾸고 자신을 돌려준다. 원본을 남기려면 `clone()` 으로 복사한 뒤 계산한다.

```javascript
const a = moment('20261116');
const b = a.add(1, 'days');

console.log(a.format('YYYYMMDD'));  // '20261117'  (a 도 바뀌었다)
console.log(a === b);               // true
```

```javascript
const a = moment('20261116');
const b = a.clone().add(1, 'days');

console.log(a.format('YYYYMMDD'));  // '20261116'
console.log(b.format('YYYYMMDD'));  // '20261117'
```

### diff 의 결과

`a.diff(b, 단위)` 는 `a - b` 다. 소수점 아래를 버린다. 단위를 생략하면 밀리초다.

```javascript
console.log(moment('20261130').diff(moment('20261116'), 'days'));       // 14
console.log(moment('20261116').diff(moment('20261130'), 'days'));       // -14
console.log(moment('20261215').diff(moment('20261116'), 'months'));     // 0  (한 달이 안 된다)
```

## Date, moment 비교

| | Date | moment |
| --- | --- | --- |
| 월 번호 | 0 부터 | 0 부터 |
| `'20261116'` 해석 | Invalid Date | 2026년 11월 16일 |
| 날짜 계산 | `setDate` 등. 원본이 바뀐다 | `add`, `subtract`. 원본이 바뀐다 |
| 1월 31일 + 1개월 | 3월 3일 | 2월 28일 |
| 해석할 수 없는 값 | 에러 없음. Invalid Date | 에러 없음. `'Invalid date'` |

---

## 정리

- Date: 날짜와 시각을 나타내는 객체. 월은 0 부터 센다.
- `new Date('YYYY-MM-DD')`: UTC 0시로 해석한다. 한국 시간으로는 9시다.
- Invalid Date: 해석할 수 없는 값으로 만든 Date. 에러가 나지 않는다.
- `set` 메서드: Date 객체의 내용을 바꾼다. 없는 날짜는 다음 달로 넘어간다.
- Date 비교: `<` `>` 는 시각을, `===` 는 참조를 비교한다.
- `toISOString`: UTC 기준이라 한국 시간과 9시간 차이가 난다.
- 날짜 문자열: 형식이 같으면 문자열 비교의 결과가 날짜 순서와 같다.
- moment: `format` 의 `MM` 은 월, `mm` 은 분이다. `add`, `subtract` 는 원본을 바꾼다.
